# 図版（SVG）の生成

`body.html` に埋め込まれている図1〜図19のインラインSVGは、このディレクトリの
スクリプトで生成しています。図を直すときは Python 側を直し、再挿入してください。

| ファイル | 内容 |
|---|---|
| `figs1.py` | 図1〜図4（3軸・崩れ方・制度の全体像・判定フロー） |
| `figs2.py` | 図5〜図10（親会社の登録比較・スケジュール・配車・書面の流れ・引取販売・労働者性） |
| `figs3.py` | 図11〜図19（社会保険のライン・ゼッケン・表示番号・車両点検・30秒チェック・二階建て・令6条の12・マニフェスト・建設工事） |
| `anchors.py` | 各図を `body.html` のどの文字列の直後に置くかの対応表 |
| `ins.py` | 挿入スクリプト。既に入っている図は飛ばします |

## 使い方

```sh
cd ../            # pdf/src/
python3 figures/ins.py figs1 figs2 figs3   # PYTHONPATH に figures/ を通して実行
python3 gen.py                              # HTML → Chromium → PDF
```

既存の図を差し替えるときは、`body.html` 内の該当 `<figure class="fig">…</figure>`
を削除してから `ins.py` を流すか、図のタイトル行を目印に置換してください。

## 約束ごと

- `viewBox` は幅1000単位に固定。A4の本文幅182mmに対応するので、**1単位 ≒ 0.182mm**。
  フォントサイズ17がおよそ9pt、13.5がおよそ7pt。
- SVGはHTML内でクリップされるため、**viewBoxをはみ出したテキストは切れます**。
  日本語1文字の幅はフォントサイズとほぼ同じなので、`文字数 × font-size` で収まるかを確認してください。
- 色・太字などのクラス（`b` `w` `gy` `nv` `n2` `gr` `rd` `am`）は `style.css` の
  「図版」セクションで定義しています。
- `marker` の `id` はHTML全体で一意である必要があります（`fa1` `fa8gr` のように図ごとに接頭辞を付けています）。
