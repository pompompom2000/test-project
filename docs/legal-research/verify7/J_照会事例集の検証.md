## J-1　【訂正】引用の仮名遣いが違っていた ― 輸送安全規則3条2項

> ……試みの使用期間中の者（十四日を超えて引き続き使用されるに**至った**者を除く。）で**あって**はならない

貨物自動車運送事業輸送安全規則は平成2年の省令で、促音は小書き。

**条文を「 」で囲って引く以上、仮名遣いまで原本どおりでなければならない。**

## J-2　【訂正】C-1の根拠条文が無関係の条文だった

照会書C-1（電子車検証における表示番号）の根拠に **道路運送車両法61条の2** を挙げていた。

**61条の2は「天災その他やむを得ない事由により継続検査を受けられない場合の、自動車検査証の
有効期間の伸長」の規定**で、電子車検証とは何の関係もない。

### 正しい条文

**道路運送車両法58条2項**

> 自動車検査証は、車台番号、使用者の氏名又は名称その他国土交通省令で定める事項が**記載**され、
> かつ、これらの事項、有効期間その他国土交通省令で定める事項（以下「自動車検査証記録事項」という。）が
> 電子的方法、磁気的方法その他の人の知覚によつては認識することができない方法により**記録**されたカードとする。

**券面に記載する事項＝施行規則35条の3**（自動車登録番号、車両識別符号、交付年月日、車名・型式、
長さ幅高さ、車体の形状、原動機の型式、燃料、総排気量、自家用／事業用の別、用途ほか）

**ICタグに記録する事項＝施行規則35条の4**（有効期間の満了日、使用者の住所、所有者、使用の本拠、
法54条1項後段等の指示内容、基準緩和の内容ほか）

### 照会が強くなった

**35条の3にも35条の4にも、ダンプ規制法の表示番号は挙がっていない。**

つまり表示番号は**備考欄への記載**であって、法67条1項の「自動車検査証記録事項」には当たらない
可能性が高い。当たらないなら、**事業の種類が変わって番号を取り直しても15日以内の変更記録は要らない。**

C-1を「当たりますか？」という白紙の質問から、
**「規則に挙がっていないので当たらないと考えますが、それでよいか」**という形に書き換えた。
条文を調べたうえで聞いていることが伝わるので、回答の質が上がる。

## J-3　【不正確】登録免許税の理由付け

22章Q4・照会書A-6(3)で、次のように書いていた。

> 登録免許税法別表第一125号は**3条・35条の許可のみ課税**

**125号の見出しは「道路運送事業の許可若しくは事業計画の変更の認可又は……の登録」**で、
**事業計画の変更の認可を含んでいる。**この書き方では、読み手に「見出しを読んでいない」と思われる。

正確には、課税されるのは**課税物件の細目**に掲げられたものだけで、その内訳は次のとおり。

| | 課税物件の細目 | 税率 |
|---|---|---|
| （二） | 道路運送法15条1項の事業計画変更認可（準特定地域の供給輸送力増加に係るもので財務省令で定めるもの） | 5千円 |
| （三） | 道路運送法43条1項 特定旅客自動車運送事業の許可 | 3万円 |
| **（四）** | **貨運法3条 一般貨物自動車運送事業の許可** | **12万円** |
| **（五）** | **貨運法35条1項 特定貨物自動車運送事業の許可** | **6万円** |
| （六）（七） | 登録貨物軽自動車安全管理者講習機関等の登録 | 各9万円 |

**貨運法9条1項の事業計画変更認可は、細目に掲げられていない。**
手数料も、貨運法61条は運行管理者試験・資格者証・貨物軽自動車安全管理者講習に限られる。

**結論（かからない）は変わらない。**理由付けだけを書き直した。

## J-7　引用を機械で突き合わせる手順

打ち直した引用は、目で読んでも崩れに気づけない（今回の「つ」と「っ」がまさにそれ）。
次の手順で機械にかけること。

```python
import zipfile, re, html, unicodedata
import pypdfium2 as p

def norm(s):
    s = unicodedata.normalize('NFKC', s)
    return re.sub(r'[\s　]', '', s)      # 空白と全角半角の違いを吸収する

# 原本（通達PDF・別添docx・e-Govの条文）をつないで1本の文字列にする
src = ''
for f in ['tsutatsu/...pdf', ...]:
    d = p.PdfDocument(f)
    src += norm("".join(d[i].get_textpage().get_text_range() for i in range(len(d))))

# 調べたい文書
x = zipfile.ZipFile('forms/運輸局照会書.docx').read('word/document.xml').decode('utf-8')
doc = norm(html.unescape(re.sub(r'<[^>]+>', '', x)))

# 引用が「文書にある」かつ「原本にもある」ことを確かめる
for name, quote in TESTS:
    q = norm(quote)
    print(name, q in doc, q in src)
```

**原本側に無ければ、こちらの打ち間違いである。**
PDFからの抽出は改行が入るので、空白を落としてから比べること。
