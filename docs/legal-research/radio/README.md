## 音声について

声は2人とも **open-jtalk**（オフラインの日本語音声合成）です。
**外部のサービスには何も送っていません。**社外に内容が出ることはありません。

声は1種類しか入っていないので、**高さ・声道・速さを変えて2人に作り分けて**います。

| | 高さ(-fm) | 声道(-a) | 速さ(-r) | 実測の基本周波数 |
|---|---|---|---|---|
| あかり | +4.0 | 0.48 | 1.08 | 中央値 159Hz |
| たくみ | −1.0 | 0.57 | 1.00 | 中央値 122Hz |

**約4.6半音離れている**ので、別人として聞き分けられます。
（測り方：有声フレームごとに自己相関で基本周波数を出し、オクターブ誤りを避けるため
最大ピークの0.75倍を超える最小ラグを採って中央値をとる。）

機械的な声なので、**正式版はご自身の声で録り直していただくほうが聞きやすい**はずです。
その場合は `台本.md` をそのまま読んでください。

音声合成が読み間違える語は、**読ませる文字列だけ**を差し替えています（台本の表記は変えていません）。
`src/gen.py` の `YOMI` にあります。傭車→ようしゃ、自重計→じじゅうけい、汚泥→おでい、など。

## 中身の出どころ

本編PDF『傭車の考え方と利用運送の登録判断』の **第65〜69章（白ダンプの早見表）** を軸に、
58〜63章（自家用ダンプの事務連絡）と70章（照会）から、
**現場でその場で判断するために要る部分だけ**を抜いて構成しました。

**7章の訂正**は `verify6/I_早見表の再検証.md` のI-1に対応します。

## 作り直し方

```bash
apt-get install -y ffmpeg open-jtalk open-jtalk-mecab-naist-jdic hts-voice-nitech-jp-atr503-m001
pip install numpy          # 声の検証にだけ使います
python3 src/gen.py
```

**台本を直すときは `src/radio.json` を直してください。**
`台本.md` は `gen.py` が radio.json から作り直すので、直接編集しても次の生成で消えます。

所要時間は4分ほど。249行を1行ずつ合成してつなぎます。
章の切れ目には短い2音のチャイムが入ります。

### 作ったあとの確認

```bash
python3 src/check.py
```

- 合成に失敗した行がないか（文字数のわりに音が短い行を探します）
- 二人の声が聞き分けられる高さの差になっているか

**耳で聞いた確認はしていません。**配る前に一度通しで聞いてください。
