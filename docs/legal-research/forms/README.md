# 書式（Word）

| ファイル | 内容 |
|---|---|
| `許可証提出依頼書.docx` | 傭車先に一般貨物自動車運送事業許可書の写し等の提出を求める依頼文＋別紙チェックシート（A4・2ページ） |

## 使う前に差し替えるところ

`〇〇` となっている箇所をすべて自社の情報に置き換えてください。

- 文書番号、発信日、提出期限
- 住所・郵便番号、代表者名、担当者名、TEL / FAX / メールアドレス
- 宛先（「お取引先各位」を個別社名にする場合）

提出を受けたら、PDF の様式6「傭車先 確認台帳」に転記して管理します
（`docs/legal-research/pdf/傭車の考え方と利用運送の登録判断.pdf` 第19章）。

## 依頼の根拠

貨物自動車運送事業法第65条の2（2026年4月1日施行）。許可・届出のない事業者への
運送委託を禁止し、違反した委託者に100万円以下の罰金（同法75条14号）。
名宛人が「何人も」であるため、委託する側が委託先の資格を確認する必要があります。

なお、ダンプ規制法の表示番号（ゼッケン）は白ナンバーでも取得できるため、
ゼッケンの有無では緑ナンバーかどうかを判断できません。車検証で「事業用」を
確認してください。

## 再生成

npm install docx
