# 照会の記録

運輸局・運輸支局・労働基準監督署・岩手県・年金事務所への照会と、その回答を保存する場所です。

- 聞くことの一覧：[`../21_運輸局への照会事例集.md`](../21_運輸局への照会事例集.md)
- 書面で出す版：[`../forms/運輸局照会書.docx`](../forms/)
- 記録する版：[`../forms/照会記録票.docx`](../forms/)

## 保存のしかた

ファイル名は `YYYYMMDD_整理番号_窓口.md`（例：`20261005_A-1_東北運輸局.md`）。
記録票をそのまま紙で保管する場合も、**要旨だけはここにテキストで残してください。**
検索できない記録は、半年後に使えません。

## 記録に必ず入れるもの

- 日付・時刻／窓口／**応対者の部署・役職・氏名**／当社の担当者
- 聞いたこと（照会事例集の整理番号）
- **回答（要約せず、言われた言葉のまま）**
- 留保の有無 ―「一般論としては」「実態によります」「個別具体の判断はできない」は**落とさずに書く**
- 前提のどれが変わると結論が変わるか
- 反映した先（本編PDFの章番号、早見表の▲番号）

## 反映したら

1. 本編PDFの該当章と早見表を直す
2. 照会事項の一覧（22章 Q1〜Q12・62章 Q13〜Q16・63章 Q17〜Q20・70章）から消し込む
3. 直した旨を、この記録にも追記する
