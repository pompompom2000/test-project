## 1. いちばん重要な結論：5つ

### ① 利用運送の登録は、原則として取る必要がない

**一般貨物の許可を持っているため、実運送のトラック事業者に傭車を出す分には第一種貨物利用運送事業の登録は不要です。**

根拠は2つの条文の組み合わせ：
- 貨物自動車運送事業法2条7項が、トラック事業者が他のトラック事業者を使うことを「**貨物自動車利用運送**」と定義
- 貨物利用運送事業法19条が、貨物自動車利用運送を同法の**適用除外**としている

→ 必要なのは**一般貨物の「事業計画変更認可」**（事業計画の「貨物自動車利用運送を行うかどうかの別」を「行う」に変更／法4条1項2号・9条1項）。**届出ではなく認可**です。

> **ただし例外が1つ。** 外注先が「利用運送専業者（自分ではトラックを持たない水屋）」の場合は、2条7項の括弧書きで適用除外から外れるため、**第一種貨物利用運送事業の登録が別途必要**になります（国交省Q&A A45）。

### ② 産業廃棄物には、利用運送も傭車も使えない

これが運送業と産廃業の最大の構造的違いです。

| | 一般貨物（普通の荷物） | 産業廃棄物 |
|---|---|---|
| 他社トラックに運ばせる | **可**（事業計画変更認可で適法化） | **原則不可**（廃掃法14条16項＝再委託の原則禁止） |
| 仲介・手配だけして口銭を取る | 可（利用運送 or 取次） | **不可**（14条15項＝無許可受託、14条の3の3＝名義貸し） |
| 契約の形 | 元請―下請の重層でよい | **排出事業者との二者間直接契約**が必須 |

- 産廃の再委託例外（令6条の12）は、**車両故障などの突発緊急時**を想定したもので、**繁忙期の恒常的な傭車は正当化できません**（東京都・群馬県とも明示）。
- 排出事業者が無許可者に委託した場合は**排出事業者自身が5年以下の拘禁刑／1,000万円以下の罰金**（法25条1項6号）。受託した側も同じ罰則（同13号）。再委託は3年以下／300万円（法26条1号）。

**実務対応**：産廃で手が足りない場合は、①排出事業者と協力会社（収運許可業者）に**直接二者間契約を結んでもらう**、②自社の運搬能力の範囲内で受注する、のいずれか。自社が間に立ってマージンを取る形は取れません。

### ③ 【2026年4月からの新リスク】緑ナンバーなしの産廃業者に「運搬だけ」を外注すると罰金

2025年6月公布のトラック適正化2法により、**2026年4月1日から法65条の2が施行**されています。

> **何人も**、無許可で一般貨物自動車運送事業を経営する者に貨物の運送を委託してはならない
> → 違反は**100万円以下の罰金**（法75条14号、両罰規定あり）

さらに、**令和8年（2026年）3月16日付 国交省事務連絡「貨物自動車運送事業法における廃棄物の運送に関する取扱いについて」**が、廃棄物運送の緑ナンバー要否を整理しました。

| ケース | 緑ナンバー（一般貨物許可） |
|---|---|
| 包括的な委託契約に基づき、**収集または処分と一体で**運搬を実施 | **不要**（自己の生業に付帯する運送） |
| **収集・処分を伴わない運搬行為のみ**を行う | **必要** |

→ **御社は緑ナンバーを持っているので、どちらの形でも適法**です。これは営業上の強みになります（運搬のみの受託ができる）。
→ 逆に、**協力会社に産廃の「運搬のみ」を頼む場面では、その会社が緑ナンバーを持っているか確認が必要**です。持っていなければ委託した御社側が罰金の対象になり得ます。※ただし②のとおり、そもそも産廃の再委託は原則禁止なので、この場面は排出事業者の直接契約に組み替えるべきです。

### ④ 荷主の位置づけ：「真荷主」と「排出事業者」は別概念

| | 貨物自動車運送事業法の「真荷主」 | 廃棄物処理法の「排出事業者」 |
|---|---|---|
| 決まり方 | **運送契約を締結した当事者**は誰か | **廃棄物を生じさせた事業活動の主体**は誰か |
| ズレる典型 | 物流子会社が親会社に代わって契約 → 子会社が真荷主 | 廃棄物を出した親会社が排出事業者 |
| 建設工事 | 運送を申し込んだ下請が真荷主になり得る | **元請業者が排出事業者**（法21条の3） |

産廃運搬の現場では、通常この2つは同じ会社（＝排出事業者が運送契約も結ぶ）になりますが、**建設現場では要注意**です。下請から運搬を頼まれても、産廃のマニフェスト交付者・委託契約の相手方は**元請**でなければなりません。

### ⑤ 産廃委託契約書だけでは、トラック法の書面交付義務を満たさない可能性がある

**これが「契約書の書き方」の核心です。**

排出事業者から産廃の収集運搬を受託するとき、御社には**2つの法律の書面義務が重畳的にかかります**。

| | 根拠 | 保存 |
|---|---|---|
| 産業廃棄物収集運搬委託契約書 | 廃掃法12条6項・令6条の2第4号・規則8条の4の2 | **契約終了日から5年** |
| 運送契約の書面交付（相互交付） | 貨物自動車運送事業法12条1項（2025年4月〜） | **1年**（下請法併用なら2年） |

**1通で兼ねることは可能ですが**、従来の産廃委託契約書のひな形には、トラック法が要求する以下の項目が入っていないことが多いです。

| トラック法の法定事項 | 従来の産廃契約書 |
|---|---|
| 運送の役務の内容及びその対価 | 「料金」欄はあるが役務内容の記載が薄い |
| **荷役作業・附帯業務の内容とその対価（運賃と別建て）** | **ほぼ入っていない** ← 最重要 |
| **待機時間料（荷待ち料）** | **ほぼ入っていない** ← 最重要 |
| **燃料サーチャージ・有料道路利用料** | **入っていないことが多い** |
| 当事者の氏名・名称**及び住所** | 通常あり |
| 運賃及び料金の**支払方法** | 通常あり |
| **書面を交付した年月日** | 契約日はあるが「交付年月日」の明示がない場合あり |

→ **対応方針**：産廃委託契約書に「運送に関する特記事項」として、積込料・取卸料・待機時間料・燃料サーチャージ・有料道路利用料を**運賃と別建てで**記載した条項（または別紙単価表）を追加する。これで1通で両法を満たせます。

**副次的なメリットが大きい**：輸送安全規則8条8号は、「荷主との契約書に実施した荷役作業等の**全てが明記されている場合**」は、乗務記録への荷役作業の記録を**1時間以上の場合に限る**としています。契約書に書いておくとドライバーの記録負担が減ります。

## 2. 運送申込書・運送引受書の書き方

**注意：令和7年4月1日施行の標準貨物自動車運送約款改正で、「送り状」の条項は削除され、「運送申込書（第6条）」「運送引受書（第7条）」になりました。**

- **運送申込書** ＝ 荷主（申込者）が作成して運送会社に出す
- **運送引受書** ＝ 運送会社が作成して荷主に返す
- 実務上は**1枚の様式で兼用**するのが効率的。国交省Q&A（p.8）に様式例あり

記載項目の完全チェックリストは [04_契約書・運送申込書の書式.md](04_契約書・運送申込書の書式.md) のC-1表を参照。特に落としやすいのは：

- [ ] **積込料・取卸料を運賃と別建てで記載**（個建運賃でも別建て必須。時間制運賃のみ包含可、ただし作業が発生する旨は明記）
- [ ] **待機時間料（見込み待機時間＋30分あたり単価）**
- [ ] **燃料サーチャージ**（基準価格と改定ルール）
- [ ] **有料道路利用料**（実費精算なら精算方法の明記で金額記載は不要）
- [ ] **当事者の住所**（社名・電話だけでは不足）
- [ ] **書面の交付年月日**

**電話だけの受注は違反です**（Q&A問2-15）。電話連絡後「直ちに」書面またはメールを交付する運用にしてください。メール本文に法定事項を直書きする形でOKですが、**相手方の事前承諾が必要**です（一度取れば都度不要）。

### 🟡 6か月以内に整備すべき体制

**実運送体制管理簿（法24条の5）**
- 対象：真荷主から引き受けた**1.5トン以上**の貨物で、**一部でも他社に運ばせた**もの。全部自社運送なら不要。
- 記載：実運送事業者の商号／貨物の内容・区間／**請負階層**
- 保存：**運送完了日から1年間、営業所に備置き**
- **様式自由。既存の配車表を流用してOK。電磁的記録可**
- 定期提出は不要だが、**監査・トラック物流Gメンの調査で求められたら提出義務**
- 真荷主から**閲覧・謄写を請求されたら応じる義務**あり

**下請（傭車）への通知フロー**
- 元請として傭車を出すとき、委託先に①元請の連絡先 ②真荷主の商号 ③委託先の請負階層 を通知する義務（法24条の5第2項）。

**委託次数の制限（2026年4月〜の努力義務、法23条の4）**
- 実務上は「元請＝0次」として**2次請けまで**に制限するルールを契約条件に入れる。

**健全化措置（法24条1項、努力義務）**
- 傭車費用の概算額を把握してから発注し、荷主提示運賃が概算を下回るなら**交渉の申出を記録に残す**。

**業務記録（全車両に拡大、2025年4月〜）**
- 荷主都合の**30分以上の荷待ち**、**1時間以上の荷役等**を記録し1年保存。
- → 待機時間料・積込料を請求する根拠になり、荷主是正指導（トラック・物流Gメン）への申告証拠にもなります。

**白トラ点検（2026年4月〜、法65条の2）**
- 委託先が緑ナンバーを持っているかの確認手順を与信チェックに組み込む。

**変更届の棚卸し（産廃）**
- 車両の増減、役員の就退任、5％以上の株主の異動、政令使用人（営業所長）の交代、営業所移転。
- 期限は**変更の日から10日以内**（登記事項証明書を添付する氏名・名称・役員の変更は**30日以内**）。届出漏れ・虚偽は**6月以下の拘禁刑／50万円以下の罰金**（法29条1号）。
- **役員の変更届漏れは特に危険**：未届役員が欠格要件に該当していた場合、更新時に判明すれば不許可、許可後判明なら取消。

### 🟢 中長期（〜2028年6月）に備える

**トラック事業許可の5年ごと更新制**
- トラック適正化2法により導入予定（公布後3年以内＝2028年6月11日まで）。審査基準は未公表ですが、**書面交付・実運送体制管理簿・運送利用管理規程の遵守状況が確認される可能性が高い**と見ておくべきです。今から証跡を残す運用に。

**「適正原価」制度と標準的運賃の廃止**
- 同じくトラック適正化2法で、大臣が定める「適正原価」を下回る運賃の制限が導入され、これに伴い**標準的な運賃は廃止**される方針（近畿運輸局資料）。
- → **自社原価を継続的に算定できる管理会計の構築**が必要になります。

**優良産廃処理業者認定を取るか**
- メリット：許可有効期間が**5年→7年**、営業上の差別化（大手・自治体・ゼネコン向け）
- ハードル：ISO14001またはエコアクション21の取得（半年〜1年）、JWNET加入、**申請日前6か月間の継続的な情報公開**（直前3年の月別運搬量・財務諸表・料金提示方法まで開示）、財務基準（3年連続で債務超過なし等）
- → 狙うなら**更新の1年半前から準備**が必要です。

## 3.5 岩手県固有で、特に押さえるべき4点

### ① 盛岡市への二重申請は不要です
**岩手県知事許可だけで、盛岡市内を含む県内全域で収集運搬ができます。** 県・市の双方が公式に明記しています。

例外は2つだけ：
- **盛岡市内でのみ積卸しを完結する**業をする場合
- **盛岡市内に積替え・保管施設を設ける**場合（この場合は先に盛岡市で積替え保管の許可を取り、その上で県の収集運搬許可を取る順序）

→ 積替え保管なしの通常の運送であれば、盛岡市への申請・手数料は不要です。

### ② 【運送会社に直撃】緑ナンバーの借用は不可、他社名入り車両も不可
岩手県が変更届の留意事項として明記しています。

- **「緑ナンバーは借用不可」** — 他社の緑ナンバー車を借りて産廃収集運搬車として届け出ることはできません
- **他事業者の名称が標記してある車両は使用不可** — 元請名・荷主名が入った車両に注意
- 借用車両は賃貸借契約書等の写しを添付し、**名義貸しの内容とならないこと**
- 車検証は**申請日に有効期間内**であること（更新直前に車検切れ車両が紛れる事故が起きやすい）
- 車両側面の表示（「産業廃棄物収集運搬車」「事業者名」「許可番号下6桁以上」）が、**カラー写真・前面と側面の2方向**で全文字判読できること。荷台のシートで隠れていないこと

→ **更新申請の前に、全車両の棚卸しと、前回許可以降の増減について10日以内の変更届が出ているかの確認**をしてください。

### ③ 債務超過・繰越損失があると、更新が通らない可能性があります
岩手県は審査基準を公表しており、全国でも厳しめの部類です。

| 状況 | 必要になるもの |
|---|---|
| 最新決算で**債務超過**（自己資本比率がマイナス） | **中小企業診断士または公認会計士**が作成した**経営診断書**（今後5年間の収支計画付き） |
| 最新決算で**繰越損失**が計上されている | **事業改善計画書**（県に参考様式あり／5年以内に解消する計画） |

> 県は「**今後5年間の事業の収支計画において、債務超過が解消出来ない場合には不許可及び許可取消し処分になる場合があります**」と明言しています。

→ 該当しそうなら、**更新期限の1年前には税理士・診断士に相談**してください。診断書の作成には数週間〜1か月かかります。

### ④ 県外との往復には、追加の手続があります

| ルート | 必要なもの |
|---|---|
| 岩手 → 岩手（盛岡市含む） | 岩手県知事許可のみ |
| 岩手 → 宮城の処分場 | 岩手県知事許可 ＋ **宮城県知事許可**（荷卸地が仙台市内なら**仙台市長許可**） |
| 岩手 → （宮城を通過）→ 福島 | 岩手県知事許可 ＋ 福島県知事許可（**通過する宮城の許可は不要**） |
| **県外 → 岩手県内の処理施設** | 両県の許可 ＋ **岩手県の事前協議条例**（搬入の**30日前まで**に知事と事前協議、環境保全協力金あり） |

※ 事前協議の義務主体は**県外排出事業者**ですが、実務上は運送側で履行を確認しないと搬入できません。
※ 荷卸地が政令市・中核市の場合の許可要否は自治体ごとに運用が異なります（岩手県のように県許可でカバーするとは限りません）。東北の該当市：仙台市、青森市、八戸市、秋田市、山形市、福島市、郡山市、いわき市。

### おまけ：岩手県には独自の「格付け制度」があります
全国制度の優良認定（有効期間7年）とは**別に**、県条例に基づく★1〜★3の格付け制度があり、岩手県産業資源循環協会が運営しています。**格付け業者に委託する場合は県外産廃の搬入期間の延長が認められる**など実利があります。

## 4. 「利用運送をすべきか」への回答

**結論：一般貨物の事業計画変更認可で足ります。第一種貨物利用運送事業の登録を新たに取る積極的な理由は、現時点では見当たりません。**

判断フロー：

1. 荷主に対して**運送責任を負っているか**？ → 負っていないなら（純粋な紹介・取次）そもそも不要
2. 外注先は**実運送のトラック事業者**か？ → Yes なら**事業計画変更認可のみ**（登録不要）
3. 外注先に**利用運送専業者（水屋）**が含まれるか？ → Yes なら**第一種登録が必要**
4. 船舶・鉄道・航空を使うか？ → Yes ならそのモードの第一種登録（モーダルシフトでRORO船を継続利用する場合など）
5. 運ぶのは産業廃棄物か？ → Yes なら**利用運送スキーム自体が使えない**

あわせて考慮すべき点：
- **登録を取ると規制が増える**。2026年4月から、書面交付・実運送体制管理簿・健全化措置・運送利用管理規程といった義務が**貨物利用運送事業者にも準用**されます（法37条）。
- 利用運送事業者は荷主に対して**自ら運送人として全責任を負います**（標準貨物自動車利用運送約款51条）。実運送会社の事故・延着・毀損も一次的に御社の賠償責任。**運送業者貨物賠償責任保険の利用運送特約**が実務上必須です。
- 運送利用管理規程・運送利用管理者の選任義務は「**前年度の利用運送に係る貨物取扱量100万トン以上**」が基準（車両台数ではありません）。中小規模なら通常は対象外です。
