## 2. H1　社会保険の賃金要件の削除（2026年10月1日施行）

**根拠**：令和7年法律第74号「社会経済の変化を踏まえた年金制度の機能強化のための国民年金法等の一部を改正する等の法律」

### 条文の比較（e-Gov原文）

**厚生年金保険法12条5号**

| | 現行（2026年5月25日施行版） | 2026年10月1日施行版 |
|---|---|---|
| 柱書 | 4分の3未満の短時間労働者に該当し、かつ、**イからハまで**のいずれかの要件に該当するもの | 4分の3未満の短時間労働者に該当し、かつ、**イ又はロ**のいずれかの要件に該当するもの |
| イ | 一週間の所定労働時間が二十時間未満であること | （同左） |
| ロ | 報酬……について……算定した額が、**八万八千円未満**であること | **削除**。旧ハが繰り上がる |
| ハ | 高等学校の生徒、大学の学生その他の厚生労働省令で定める者であること | → ロへ |

**健康保険法3条1項9号**も同一の改正（`211AC0000000070_20260801_508AC0000000031` と `211AC0000000070_20261001_507AC0000000074` を比較し、柱書の「イからハまで」→「イ又はロ」、ロ（八万八千円未満）の削除、ハ→ロの繰上げを確認）。

### 意味

賃金がいくら低くても、それだけでは適用除外にならない。**週20時間以上で学生でなければ**、（特定適用事業所であれば）被保険者になる。
いわゆる「年収106万円の壁」を作っていた条文上の根拠が消える。

### 当社への影響

**判定方法そのものは変わらない。**当社は特定適用事業所（常時50人超）ではないので、健保・厚年は**4分の3基準のみ**で判定する。
ただし車持ち運転手を日雇いで雇うときの説明が変わるので、PDF 35〜39章・図11・ノート14を更新した。

### 解消した留保

PDF 36章に「賃金要件の撤廃時期は、法律が『公布から3年以内の政令で定める日』とする一方、日本年金機構は『令和8年10月に撤廃予定』と公表しており**食い違っています**」と書いていた。
**この留保は解消した。**e-Govの条文で2026年10月1日施行が確定しており、日本年金機構の公表どおりである。

## 3. H2　貨運法の未施行部分（2028年6月10日施行）

**根拠**：令和7年法律第60号。`401AC0000000083_20260521_505AC0000000063`（現行）と `401AC0000000083_20280610_507AC1000000060` の全条文を機械的に比較した。

### 新設される条文（原文の要点）

**法6条の2（許可の更新）**
> 第三条の許可は、国土交通省令で定めるところにより**五年ごとにその更新**を受けなければ、その期間の経過によって、その効力を失う。（1項）
> 更新の申請があった場合において、有効期間の満了の日までに当該申請に対する処分がなされないときは、従前の第三条の許可は、**有効期間の満了後もその処分がなされるまでの間は、なおその効力を有する**。（2項）
> 国土交通大臣は、**別に法律で定める独立行政法人**に……**許可の更新に関する事務の一部を行わせることができる**。（4項）

**法9条の2（運賃及び料金に係る適正原価）**
> 国土交通大臣は、……**燃料費、全産業の労働者一人当たりの賃金の額の平均額を踏まえた人件費、減価償却費、輸送の安全確保のために必要な経費、委託手数料、事業を継続して遂行するために必要不可欠な投資の原資、公租公課**その他の……費用であって国土交通省令で定めるものを的確に反映した積算を行うことにより、貨物自動車運送事業の適正な運営を図るための原価を定めることができる。（1項）
> ……定めたときは、遅滞なく、これを**告示**しなければならない。（2項）

**法9条の3（適正原価を下回る運賃及び料金の制限）**
> 一般貨物自動車運送事業者は、……**自らが引き受ける貨物の運送に係る運賃及び料金が当該適正原価を下回ることとならないようにしなければならない**。（1項）
> 一般貨物自動車運送事業者は、……自らが引き受ける貨物の運送について**他の貨物自動車運送事業者の行う運送**（自動車を使用しないで貨物の運送を行わせることを内容とする契約によるものを除く。）**を利用するときは、その利用する運送に係る運賃及び料金が当該適正原価を下回ることとならないようにしなければならない**。（2項）

> **【当社に直結】** 2項は**傭車に出すときの単価**を名指しで捉えている。
> さらに**法37条1項に「第九条の三」が加えられ、第一種貨物利用運送事業者にも準用**される。
> 読替表により、9条の3第2項の「他の貨物自動車運送事業者」は「貨物自動車運送事業者又は**他の第一種貨物利用運送事業者**」となる。

**法24条の6（労働者の適切な処遇の確保）**
> 一般貨物自動車運送事業者は、……その事業用自動車の運転者その他の労働者が有する**知識、技能その他の能力についての公正な評価に基づく適正な賃金の支払**その他の労働者の適切な処遇を確保するために必要な措置を実施するものとする。

### 削除される条文

**附則1条の3（標準的な運賃）** ― 2028年6月10日施行版に存在しないことを確認。
**＝ 標準的な運賃の廃止日が2028年6月10日で確定した。**これまで「廃止予定・廃止日は未確定」としてきた記述を更新する。

### 条ずれのみの変更

75条・65条・24条の5・37条の各所で「第三十五条**第六項**」→「第三十五条**第八項**」。特定貨物自動車運送事業の準用規定の項ずれによるもので、内容は不変。

### 要修正として残ったもの

ノート00の「適正原価（**2027年春頃告示見込み**）」は、根拠条文（法9条の2）の施行日が**2028年6月10日**であることと整合しない。
法律本体に準備行為の規定は見当たらなかった。**告示時期は照会事項Q22に回した。**

## 4. H3　貨運法 附則1条の2の2の実在を確認

ノート17に「**貨運法附則1条の2の2**（既存資料が引く荷主要請・勧告・公表の根拠条文）の現行の有無と内容。本調査では本則65条の2・75条14号しか確認できなかった。**東北運輸局へ併せて照会**」と残していた宿題。**解決した。**

| 条文 | 見出し | 対象 | 段階 |
|---|---|---|---|
| **附則1条の2** | 違反原因行為への対処 | 貨物自動車運送事業者が**貨運法・命令に違反する原因**となるおそれのある行為を荷主がしている場合 | ①情報提供 → ②**荷主の理解を得るための措置**（働きかけ）→ ③要請 → ④勧告（**65条1項で勧告できる場合を除く**）→ ⑤公表 |
| **附則1条の2の2** | **無許可経営等原因行為への対処** | **貨物自動車運送事業者以外の者による貨物自動車運送事業の経営（＝白トラ）の原因**となるおそれのある行為を**荷主等**がしている場合 | ①情報提供 → ②要請 → ③勧告 → ④**公表するものとする**（裁量ではない） |

- 附則1条の2の2の「荷主等」には、**法64条各号に掲げる者を含む**（1項括弧書）。
- 同条3項の勧告には、附則1条の2第4項のような**65条1項との調整のただし書がない**。
- 同条6項：**地方実施機関**は、無許可経営等をする者に対する荷主等の行為が無許可経営等原因行為に該当すると疑うに足りる事実を把握したときは、その事実を国土交通大臣に**通知するものとする**。
- 「特定第二種貨物利用運送事業者」（37条の2第3項）も貨物自動車運送事業者に含めて読む。

> **結論：白トラへの委託は、刑事罰（65条の2・75条14号・80条）と行政措置（附則1条の2の2）の二本立てである。**
> PDF ケース⑥に追記した。ノート17の照会事項からは削除してよい。

## 5. H4　廃掃法の令和8年改正（2026年9月16日施行）― 実質的影響なし

**根拠**：令和8年法律第43号「廃棄物の処理及び清掃に関する法律等の一部を改正する法律」（公布2026年6月19日）。
段階施行で、**2026年6月19日 / 2026年9月16日 / 2028年12月18日**の3段階。

`345AC0000000137_20260701_508AC0000000022`（改正前）と `345AC0000000137_20260916_508AC0000000043`（改正後）の**全条文を条単位で機械比較**した。変更のあった条は27。
そのうち当社の論点に関わるものは次のとおり。

| 条文 | 変更内容 | 当社への影響 |
|---|---|---|
| **21条の3第4項** | 引用が「第六条の二**第六項及び第七項**」→「同**第八項及び第九項**」 | **なし。**「下請負人を事業者とみなす」本文と、産廃許可を持つ下請を除く括弧書は不変（PDF 57章・図19） |
| **26条1号** | 同じく「第六条の二第七項」→「第九項」 | **なし。**「**第十四条第十六項**……の規定に違反して……委託した者」は不変。法定刑（3年以下の拘禁刑若しくは300万円以下の罰金、又は併科）も不変 |
| **25条1項6号** | 「第六条の二第六項」→「第八項」 | **なし。**13号（14条15項違反＝無許可受託）は不変 |
| 14条の2・14条の5 | 7条の2**第5項**の準用が削除 | **なし。**当社の記述で引用していない |

**14条16項（再委託禁止）の本体は変わっていない。**改正後の原文を再確認した：
> 産業廃棄物収集運搬業者は、産業廃棄物の収集若しくは運搬又は処分を、産業廃棄物処分業者は、産業廃棄物の処分を、それぞれ他人に委託してはならない。
> ただし、**事業者から委託を受けた**産業廃棄物の収集若しくは運搬又は処分を政令で定める基準に従つて委託する場合**その他環境省令で定める場合**は、この限りでない。

**なお当社の廃掃法の条文確認は2026年9月18日に行っており、すでに改正後の条文で検証していた。**したがって既存記述に誤りはない。

**未施行**：同改正の残りが2028年12月18日に施行される。
**廃掃法施行規則**には2027年4月1日施行の改正が2件（令和7年4月22日公布・令和8年3月30日公布）。**内容は未確認。年明けに再確認する。**

## 6. H5　企業規模要件の段階的引下げは条文で確認できない【要修正】

PDF 36章の表に「2027年10月に36人以上 → 2029年10月に21人以上 → 2032年10月に11人以上 → 2035年10月に全企業」と載せていた。

**e-Govに反映されている厚生年金保険法の改正版を、2026年5月25日（現行）／2027年10月1日／2029年4月1日／2029年10月1日の各版について開き、

## 9. 次回この棚卸しをするときの手順

```python

import json, urllib.request
def revs(law_id):
    u = f'https://laws.e-gov.go.jp/api/2/law_revisions/{law_id}?response_format=json'
    with urllib.request.urlopen(u) as r: d = json.load(r)
    return sorted(d['revisions'], key=lambda x: x.get('amendment_enforcement_date') or '')

# 施行日ごとの版の条文を取って条単位で比較する
```
