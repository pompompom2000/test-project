# ▲1〜▲12 の図解 ― Gemini 画像生成プロンプト集

早見表（`../pdf/白ダンプの早見表.pdf` 第69章）の **▲1〜▲12** を、絵で分かるようにするための
プロンプトです。そのままコピーして Gemini に貼ってください。

各▲に **2枚**を用意しています。

| | 役割 | 絵柄 | 使う場所 |
|---|---|---|---|
| **A 本編カット** | 「何が条件か」を1枚で見せる | フラットなベクター図 | 早見表の各▲の冒頭 |
| **B 理解度チェック** | 「これは○か×か」を考えさせる | 実写ふうの現場写真 | 朝礼・安全会議・入社時教育 |

Bは**答えを画像に入れていません。**裏に答えと根拠を書いて配るか、朝礼で出題して使ってください。
答えは各プロンプトの「答え」欄にあります。

---

## 先に読んでください ― 3つの約束

### 1. 数字は画像に描かせない

画像生成AIは**数字と条文番号を平気で作り変えます。**「200mm」が「20mm」に、「38条」が「88条」に
なっても、絵として自然なので気づきません。**寸法・条文番号・金額・時間数は画像に入れず、
キャプション（図の下の文字）に書いてください。**

このプロンプト集では、画像に入れる数字を **「3面」「1m」「2か所」** など、
間違えたら一目で分かるものだけに絞ってあります。

### 2. 日本語は必ず検品する

Gemini の画像モデル（Nano Banana Pro ＝ Gemini 3 Pro Image）は日本語もかなり描けますが、
**濁点が落ちる・画数の多い漢字が崩れる・指定していない文字が増える**ことがあります。
生成したら、後ろの「検品チェックリスト」を必ず通してください。

**どうしても文字が崩れるときは、**プロンプトの文字指定をすべて消して
**「文字を一切入れない絵」だけを生成し、**文字はこちらで `body.html` の上から載せます。
そのほうが確実で、修正もききます。ご相談ください。

### 3. 実在のものは描かせない

実在の社名・ロゴ・車体広告・読み取れるナンバープレートの数字・特定の個人に似た顔は
入れないよう、共通スタイルに書き込んであります。**消さないでください。**

---

## モデルと設定

- **モデル：Nano Banana Pro（Gemini 3 Pro Image）**を使ってください。文字を描かせるならこれ以外は厳しいです。
  Gemini アプリなら画像生成、AI Studio なら画像モデルを選びます。
- **Aカットは 16:9 の横位置。**早見表の図版枠（幅182mm）にそのまま入ります。
- **Bカットは 3:2 の横位置。**
- **絵柄をそろえるコツ：**2枚目以降は、**1枚目に出来上がった画像を添付して**
  「この絵柄・この配色のまま、次は▲2を描いて」と頼むと、12枚が1セットに見えます。
  早見表PDFの図25のページを画像で添付して「この配色に合わせて」と言うのも有効です。

```
画面の上端の濃紺の帯に、白抜きで「「一体だから許可は要らない」と言われた。運搬だけ請けてよいか」と入れる。
```
**答え：× 通りません。**一体的実施の整理が使えるのは、**収集運搬と処分の両方を請け負う場合**です。当社は処分業の許可を持っていないので、この型は使えません。**産廃の運搬を請け負うなら緑ナンバー（収集運搬業許可＋事業用自動車）が要ります。**

---

### B-10（▲10に対応）

**問いの文：**`午前は他社で走ってきた。午後、当社で何時間まで乗せられるか`
**場面：**
```
【共通スタイル】←上の共通スタイルBを貼る

昼過ぎの砕石ヤード。大型ダンプから降りてきた運転者が、
当社の配車担当と立ち話をしている。運転者は疲れた様子で、手に軍手を持っている。
背景に、別の会社の大型ダンプが走り去っていく後ろ姿が小さく写っている。
画面の上端の濃紺の帯に、白抜きで「午前は他社で走ってきた。午後、当社で何時間まで乗せられるか」と入れる。
```
**答え：▲ その場で聞いても遅い。**労働時間は事業主が違っても通算されます（労基法38条1項）。**副業・兼業の届出制を先に作っておき、朝の時点で他社の勤務を申告させてください。**加えて「管理モデル」で各社の上限を開始前に決めておけば、他社の実労働時間を把握しなくても法を守れます。届出書と上限設定書のWord版があります。

---

### B-11（▲11に対応）

**問いの文：**`日雇いだから点呼は省いてよいか`
**場面：**
```
【共通スタイル】←上の共通スタイルBを貼る

早朝の運送会社の車庫。緑ナンバーの大型ダンプが並んでいる。
ナンバープレートは緑地で、数字は写らない角度かぼかす。
運転者が1人、アルコール検知器と点呼記録簿が置かれた点呼台の横を素通りして、
車両のほうへ歩いていく。点呼台に運行管理者はいない。
画面の上端の濃紺の帯に、白抜きで「日雇いだから点呼は省いてよいか」と入れる。
```
**答え：× 日雇いでも当社の運転者です。**点呼・乗務記録・初任診断・教育はすべて必要（輸送安全規則3条・7条・10条）。**省けば行政処分の対象です。**

### B-12（▲12に対応）

**問いの文：**`工区をまたぐので公道を横切る。場内扱いでよいか`
**場面：**
```
【共通スタイル】←上の共通スタイルBを貼る

2つの工事現場にはさまれた片側1車線の一般道を、真横から撮った写真。
道路の左右に仮囲いとゲートがあり、どちらも工事現場になっている。
1台の大型ダンプが、左の現場のゲートから出て道路を横切り、
右の現場のゲートへ入ろうとしている。一般の乗用車が1台、その手前で停まっている。
画面の上端の濃紺の帯に、白抜きで「工区をまたぐので公道を横切る。場内扱いでよいか」と入れる。
```
**答え：× 公道に出た瞬間に外れます。**「すぐそこだから」は通りません。出た瞬間に貨運法とダンプ規制法の両方がかかるので、早見表67章のⅠ〜Ⅳのどれに当たるかで判定し直してください。

## 検品チェックリスト

生成した画像は、**1枚ずつ**次を確認してから使ってください。

- [ ] **指定していない文字が増えていないか。**とくに画面の隅、車体、書類の中
- [ ] **濁点・半濁点が落ちていないか。**「ダンプ」が「タンフ」になっていないか
- [ ] **漢字が崩れていないか。**「請」「検」「廃」あたりが化けやすい
- [ ] **○と×が入れ替わっていないか。**ここを間違えた画像を配ると、早見表より害があります
- [ ] **数字が入っていないか。**入っていたら、たとえ正しくても消してください（キャプションに書く約束です）
- [ ] **実在の社名・ロゴ・読めるナンバープレートが写っていないか**
- [ ] **Bカットに答えが写り込んでいないか。**チェックマーク・赤丸・矢印など

1つでも引っかかったら、**その項目だけを指摘して同じ会話で描き直させてください。**
プロンプトを最初から貼り直すより早く、絵柄も揃います。
