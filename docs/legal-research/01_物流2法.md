## 2. 改正貨物自動車運送事業法（トラック法）

### 2-1. 運送契約締結時の書面交付義務

**根拠条文：法第12条第1項（真荷主⇔事業者の相互交付）／法第24条第2項（委託先への交付）**

- **法12条**：真荷主と一般貨物自動車運送事業者が運送契約を締結するときは、法定事項を記載した書面を**相互に交付**（双方義務）。
- **法24条2項**：事業者が利用運送を行うときは、**委託先へ交付**（片務。相互交付の便宜的取扱いは認められない＝Q&A問2-22）。
- **「真荷主」の定義（法12条2項）**：①自らの事業に関して ②トラック事業者・貨物利用運送事業者と運送契約を締結して運送を委託する者で ③トラック事業者・貨物利用運送事業者以外のもの。一般消費者は含まれない。個人事業主は該当する（Q&A問1-4）。オフィス移転・従業員の引越は該当しない（問1-5）。

**【法定記載事項（6項目）】**
1. 運送の役務の内容及びその対価
2. 運送の役務以外の役務（荷役作業・附帯業務等）が含まれる場合、その内容及びその対価
3. その他特別に生じる費用に係る料金（有料道路利用料、燃料サーチャージ等）
4. 契約当事者の氏名・名称及び住所
5. 運賃・料金の支払方法
6. 書面の交付年月日

- **積込料・取卸料は「運送の役務以外の役務」として別建て記載が必要**（時間制運賃・個建運賃でも同様。Q&A問2-3〜2-5）。
- **待機時間料（30分〜）も明確化対象**（リーフレット）。
- **電磁的方法：可**。ただし**相手方の承諾がある場合に限る**（法12条3項・24条3項、政令）。メール本文に法定事項を記載する方式もOK。受託側は引用返信で「引き受ける旨」を書けば法定事項の再記載不要（Q&A問2-23）。
- **交付書面の写しは1年間保存**。紙をPDF化して保存すれば原紙の保存は不要（問1-6）。
- **例外**：「災害その他緊急やむを得ない場合」、真荷主が郵便物・信書便物の運送を委託する場合（12条のみ）。**スポット輸送は例外に該当しない**（問2-17・2-18）。
- **中小受託取引適正化法（旧下請法）との重複**：同法4条の明示・書面交付をした事項は記載不要（法24条2項ただし書）。

出典：[e-Gov 貨物自動車運送事業法](https://laws.e-gov.go.jp/law/401AC0000000083)／[国交省リーフレット「運送契約締結時の書面交付義務化」](https://www.mlit.go.jp/jidosha/content/001865379.pdf)

### 2-2. 実運送体制管理簿

**根拠条文：法第24条の5**

| 項目 | 内容 |
|---|---|
| 作成主体 | **元請事業者**＝真荷主から運送を引き受けた一般貨物自動車運送事業者（貨物軽自動車運送事業者は除く）。**2026年4月1日以降は元請となる貨物利用運送事業者も対象**（Q&A問4-3・4-13） |
| 対象 | 真荷主から引き受けた**1.5トン以上**の貨物で、その全部または一部について**利用運送を行った**もの。全部自社実運送なら不要 |
| 1.5トンの判定 | 実運送時ではなく**真荷主から引き受ける際の重量**（1運送依頼単位）。積合せ運送も同じ基準 |
| 記載事項 | ①実運送事業者の商号又は名称 ②実運送を行う貨物の内容及び区間 ③**請負階層**（真荷主との運送契約の後に締結された運送契約の数＝一次請け・二次請け…）④その他省令事項 |
| 保存 | **運送が完了した日から1年間、営業所に備置き** |
| 形式 | **様式自由**。既存の配車表流用可。**電磁的記録での作成・保存可** |
| 通知義務 | 元請→委託先：①元請の連絡先 ②真荷主の商号・名称 ③委託先の請負階層（法24条の5第2項）。中間事業者→さらに下位へ同様に通知（3項）。実運送事業者→元請へ①〜③を通知（4項） |
| 真荷主の権利 | **業務取扱時間内はいつでも閲覧・謄写を請求できる**（法24条の5第5項） |
| 例外 | 「災害その他緊急やむを得ない場合」／下請構造が固定化し一連の委託関係が明らかな場合は運送ごとの作成不要（1項ただし書、Q&A問4-11） |
| 提出 | 定期提出は不要。ただし**監査・トラック物流Gメン調査で求めがあれば提出必要**（問4-17） |

### 2-3. 多重下請構造の是正：健全化措置・委託次数制限

**根拠条文：法第24条第1項（健全化措置）／法第23条の4（委託次数の制限。2026年4月1日〜）**

**健全化措置（努力義務、法24条1項各号）**
1. 利用する運送に要する**費用の概算額を把握**した上で、その概算額を勘案して利用の申込みをすること
2. 荷主が提示する運賃・料金が①の概算額を下回る場合、当該荷主に対し**運賃・料金の交渉をしたい旨を申し出る**こと
3. 委託先がさらに利用運送する場合に関し、**「二以上の段階にわたる委託の制限（再々委託の制限）」等の条件を付す**こと
4. その他省令で定める措置

**委託次数の制限（法23条の4、2026年4月1日〜）**
- 元請として真荷主から引き受けた運送について、**他事業者からの二以上の段階にわたる委託を制限するために必要な措置**を講ずる**努力義務**。
- 実務上は「元請＝0次」として**2次請け（再々委託）まで**に制限するルールを設ける（近畿運輸局資料）。
- 一般貨物だけでなく、**貨物利用運送事業者・軽貨物・特定貨物**にも適用。
- 罰則・行政処分なし。ただし運賃の不当据置き等があれば**トラック・物流Gメンの是正指導対象**（Q&A問3-5）。

### 2-5. 軽トラック事業（貨物軽自動車運送事業）の規制強化（2025年4月1日〜）

### 2-6. 「標準的な運賃」制度との関係

- 根拠：**法附則第1条の3**（「当分の間」大臣が標準的な運賃を定めることができる）。
- **令和6年3月22日／国土交通省告示第209号**で改定：運賃水準を**平均8%引上げ**、**待機時間料**（30分ごと：小型1,670円／中型1,760円／大型1,890円／トレーラ2,220円）、**積込料・取卸料**（中型・機械荷役2,180円、手荷役2,100円／30分）、荷役2時間超は**5割増**、下請手数料等を新設。

- **⚠️将来**：トラック適正化2法により「**適正原価**」制度が導入され、**標準的運賃は廃止**される方針（近畿運輸局資料に明記）。施行は公布後3年以内＝**2028年6月11日まで**。適正原価の告示までに2年の経過措置。

## 3. 改正物流効率化法（物資の流通の効率化に関する法律）

### 3-1. 努力義務の対象と内容（2025年4月1日〜）

- 対象：**①荷主（第一種荷主・第二種荷主）②連鎖化事業者（FC本部）③貨物自動車運送事業者等④貨物自動車関連事業者（倉庫・港湾運送・鉄道・航空）**。元請トラック事業者・利用運送事業者には**荷主に協力する努力義務**。
- **第一種荷主（法30条8号）**：自らの事業に関して**継続して**トラック事業者・貨物利用運送事業者と運送契約を締結する者（主に発荷主。引取物流では着荷主）。
- **第二種荷主（法30条9号）**：自らの事業に関して**継続して**運転者から貨物を受け取る／引き渡す者（運送契約は締結しない。主に着荷主）。
- **連鎖化事業者**：FC本部で、加盟店とドライバー間の貨物受渡し日時を**指示できる**場合に該当。

### 3-2. 判断基準（省令）の3分野

**根拠**：荷主向け＝「荷主の貨物自動車運送役務の持続可能な提供の確保に資する運転者の運送及び荷役等の効率化に関する判断の基準となるべき事項を定める命令」（令和7年内閣府等9府省令第1号）／トラック事業者向け＝令和7年国土交通省令第5号

| 分野 | 主な取組事項 |
|---|---|
| **積載効率の向上等** | 必要なリードタイムの把握・確保／出荷量・入荷量の平準化／受渡し日・時間帯の集約／配車計画・運行経路の最適化（システム導入）／輸送網の集約・共同配送／帰り荷の確保（実車率向上）／大型車導入／社内関連部門（開発・生産・流通・販売・調達・在庫管理）の連携 |
| **荷待ち時間の短縮** | 入出荷日時の分散／**トラック予約受付システム（到着時刻表示装置）**の導入・活用／寄託先施設での入出庫日時分散 |
| **荷役等時間の短縮** | **パレット化**・標準化／検品の簡略化・省略／テールゲートリフター等の導入／荷役施設の整備 |

- **荷待ち時間の定義（法30条4号・規則5条）**：集貨場所等に到着した時刻（指示時刻がある場合は指示時刻／到着後速やかに受付した場合はその時刻）から**荷役等開始時刻**までの、**荷主等の都合**による待機時間。ドライバーの到着遅れに起因する分は含まない。
- **KPI（法目標）**：施行後3年で（2019年度比）荷待ち・荷役時間を**1人あたり年間125時間削減**、積載率向上により輸送能力**16%増**（積載効率44%）。

出典：[トラック事業者向け判断基準の解説書（令和8年1月）](https://www.mlit.go.jp/seisakutokatsu/freight/content/001984867.pdf)／[「物流効率化法」理解促進ポータルサイト](https://www.revised-logistics-act-portal.mlit.go.jp/)

### 3-3. 特定事業者の指定基準（政令：令和7年8月公布）

| 区分 | 指定基準 |
|---|---|
| 特定第一種荷主／特定第二種荷主／特定連鎖化事業者 | 年度の**取扱貨物の重量が9万トン以上** |
| 特定倉庫業者 | 年度の**貨物の保管量が70万トン以上** |
| 特定貨物自動車運送事業者等 | **保有車両台数150台以上**（前年度末。**被けん引車も1台としてカウント**。セミトレーラはヘッド＋シャーシで2台） |

- 考え方：大手から順に**日本全体の輸送能力の約半分**を占める事業者を指定。対象は上位**3,200社**程度と見込まれる（※社数は業界団体資料ベース、要確認）。
- **国からの一方的指定ではなく、事業者の自己判定＋届出が起点**。

### 3-5. CLO（物流統括管理者）

**根拠：法第47条（特定荷主）／法第66条相当（特定連鎖化事業者）。特定倉庫業者・特定トラック事業者には選任義務なし**

- **要件**：特定荷主が行う**事業運営上の重要な決定に参画する管理的地位にある者**（＝経営幹部クラス。単なる物流部門長では不可）。**1名**選任。
- **職務**：①中長期計画書の作成 ②ドライバーの負荷低減・過度な集中是正に向けた運営方針の作成と管理体制の整備 ③定期報告書の作成 ④関係各部門（開発・生産・流通・販売・調達・在庫管理等）間の連携体制構築と従業者の意識向上 ⑤情報処理システム・設備の整備、物流器具・データ等の標準化計画の作成・実施・評価 ⑥取引先その他関係者との連携・調整 ⑦報告徴収への対応。

## 4. 「荷主」の法律上の位置づけ

### 4-1. 荷主の責務・荷主勧告（貨物自動車運送事業法）

> ⚠️ **2026年4月1日施行の改正で条番号が繰り下がっています。**旧・法64条（荷主勧告）→ **現・法65条**。現行の法64条は「荷主の責務」。2025年10月の是正指導指針など施行前資料は旧条番号で書かれているので注意。

- **法第64条（荷主の責務）**：荷主は、トラック事業者が法令を遵守して事業を遂行できるよう**必要な配慮**をしなければならない。ここでいう「荷主」には、**①利用運送事業者に委託した真荷主（多段階委託の上流を含む）②他人のために貨物を受け取る者（着荷主側）③他人のために貨物を引き渡す者**を含む。
- **法第65条（荷主への勧告）**：トラック事業者が過労運転防止義務違反（法15条1〜4項）等により命令・行政処分を受ける場合で、**当該違反行為が荷主の指示に基づくことが明らかである等、主として荷主の行為に起因する**と認められ、事業者への処分のみでは再発防止が困難なときは、**国交大臣が荷主に対し勧告**できる。事前に**荷主の事業所管大臣の意見を聴取**。**勧告したときはその旨を公表するものとする（3項＝義務的公表）**。

### 4-2. 違反原因行為への対処（働きかけ・要請・勧告・公表）

**根拠：法附則第1条の2（「当分の間」の措置）**

| 段階 | 根拠 | 要件 |
|---|---|---|
| 関係行政機関への**情報提供** | 附則1条の2第1項 | 違反原因行為をしている**疑いがある**と認めるとき |
| **働きかけ** | 同2項 | 疑いがある場合。理解と協力を求め、自主的な確認・改善を促す |
| **要請** | 同3項 | 違反原因行為をしていることを**疑うに足りる相当な理由**があると認めるとき |
| **勧告** | 同4項 | 要請後もなお相当な理由があると認めるとき（※法65条1項で勧告できる場合を除く） |
| **公表** | 同5項 | 勧告をしたときは**公表するものとする** |
| 公取委への通知 | 同7項 | 独禁法の不公正な取引方法に該当すると疑うに足りる事実を把握したとき |

**違反原因行為の6類型**（是正指導指針、令和7年10月／トラック・物流荷主特別対策室）
1. **長時間の荷待ち**：1時間以上の荷待ち（荷待ちのみで把握していない場合は2時間以上の荷待ち・荷役等）が**恒常的**に発生
2. **契約にない附帯業務**：対価の合意なし（検品・棚入れ・ラベル貼り・仕分・横持ち等）。書面交付の記載の有無で判断
3. **運賃・料金の不当な据置き**：交渉申出に正当な理由なく応じない／根拠を示した交渉に説明・情報提供をせず据え置く・一方的決定
4. **過積載運送の指示・容認**
5. **異常気象時の運送依頼**（事業者が輸送中止を判断・報告したのに強要）
6. **その他、無理な運送依頼**（拘束時間超過を要する依頼、適法速度で間に合わない到着時間の強要、**法12条の書面相互交付への協力拒否**、高速料金を払わず時間指定、契約にない荷積み・荷卸しの強要 等）

- **体制**：2023年7月「トラックGメン」創設 → **2024年11月「トラック・物流Gメン」に改組**、倉庫業者からの情報収集も追加、各都道府県トラック協会の「Gメン調査員」と合わせ**総勢360名**。
- **荷主パトロール・街頭活動**も実施。情報提供者の保護規定あり。

出典：[貨物自動車運送事業法附則第1条の2に基づく荷主への是正指導指針（令和7年10月）](https://www.mlit.go.jp/jidosha/content/001913224.pdf)／[e-Gov](https://laws.e-gov.go.jp/law/401AC0000000083)

### 4-3. 違法な「白トラ」利用の禁止（2026年4月1日〜）

- **法第65条の2**：**何人も**、①無許可で一般貨物自動車運送事業を経営する者 ②無許可で特定貨物 ③無届で貨物軽自動車運送事業を経営する者に**貨物の運送を委託してはならない**。→ **荷主も名宛人**。
- **罰則：法75条14号＝100万円以下の罰金**（法80条の両罰規定により法人にも罰金）。
- **法附則第1条の2の2（無許可経営等原因行為）**：荷主等に対する情報提供・**要請**・**勧告**・**公表**の仕組みを新設。
- 注意：許可・届出の要否基準自体は変更されていない。自己の生業と密接不可分で運送の対価としての有償性が認められない場合は許可・届出不要（Q&A問5-2）。
