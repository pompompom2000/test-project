# NotebookLM の「音声概要」に貼る指示文

音声概要の生成画面に**カスタマイズ**の入力欄があります。そこに下の文をそのまま貼ってください。
**何も入れないと、一般向けの軽い雑談になります。**社内研修に使うなら必ず入れてください。

---

## A　標準（全体を通して／15〜20分を狙う）

```
聞き手は、岩手県の砕石会社と運送会社で働く配車担当と大型ダンプの運転者です。
法律の予備知識はありませんが、毎日この判断をしています。

次の方針で話してください。

1. 資料に書かれていることだけを話す。推測や一般論を足さない。
2. 条文の番号と通達の文言は、資料のとおりに正確に言う。省略しない。
3. 結論を先に言い、理由をあとから説明する。
4. 「一つでも落ちたら違法」「名前を変えても同じ」のような、
   現場で効く言い回しは、資料の表現をそのまま使う。
5. 第8章の「緑ナンバーに日雇いは乗せられない」は、この資料で最も重要な訂正です。
   ここだけは時間をかけて、なぜ取り違えたのかまで含めて説明してください。
6. 表や図を見てください、という言い方はしない。音声だけで完結させる。
7. 冗談や雑談は最小限に。親しみやすさより、聞き間違いが起きないことを優先する。
```

## B　短く（要点だけ／5〜8分を狙う）

```
聞き手は大型ダンプの運転者です。運転前に一度だけ聞きます。

次の五つだけに絞って話してください。それ以外は省いてかまいません。

1. 白ダンプに効く関門は四つあり、一つでも落ちたら残り三つが完璧でも違法であること
2. 「土砂等」と「産業廃棄物」は別の軸であること（がれき類・汚泥・砕石の違い）
3. 運送の対価を立てない。名前を変えても同じであること
4. 緑ナンバーのダンプに日雇いの運転者は乗せられないこと
5. 積み込む前に見る六項目

条文の番号は、言える範囲で正確に。推測は足さないでください。
```

## C　訂正の章だけ（3〜5分／朝礼用）

```
第8章「緑ナンバーのダンプに、日雇いの運転者は乗せられない」だけを取り上げてください。
他の章には触れなくてかまいません。

次の順で話してください。

1. 何が誤りだったのか（点呼と初任診断をすれば大丈夫、と整理していた）
2. 正しくはどうなのか（輸送安全規則3条1項・2項の文言をそのまま引く）
3. なぜ取り違えたのか（建設事業Q&Aの設問はお金の流れを聞いたもので、
   国土交通省は選任の要件に触れていない）
4. どうすれば乗せられるのか（二月を超える期間の契約にする）
5. 白ナンバーなら日雇いで構わないこと。輸送安全規則は事業用自動車の規則だから

聞き手は配車担当です。明日からの運用が変わる話として伝えてください。
```

## うまくいかないときの直し方

| 症状 | 直し方 |
|---|---|
| 雑談が多い | 指示文に「冗談や雑談は最小限に」を入れる（Aには入っています） |
| 条文番号が飛ばされる | 「条文の番号は省略せず、資料のとおりに言う」を強めに書く |
| 短すぎる | 取り上げる章を名指しで列挙する。「第1章から第13章まで順に」と書く |
| 長すぎる | Bのように章を絞る。NotebookLM側で長さを選べる場合はそちらでも |
| 資料にないことを話す | 「資料に書かれていることだけを話す。推測を足さない」を先頭に置く |

**生成されたものは、必ず一度通して聞いてください。**
音声概要は資料を要約して話し直すものなので、**条文番号や数字が入れ替わることがあります。**
社内に配る前に、原稿と突き合わせてください。
