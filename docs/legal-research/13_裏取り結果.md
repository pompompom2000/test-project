## 2. 断定を緩和した箇所（主なもの）

- 判定B「登録は不要です／完全に適法」→「A1の趣旨から**不要と解される**」。販売商品の着地渡し配送を名指しした公式見解はQ&Aにない。
- 「基本契約書＋単価表で日々の書面交付は不要」→ 問2-12は「役務の内容が日々変動しない場合」。積込地・数量が日々変わる砕石配送では配車表等を法定書面として交付する整理が安全。
- 「誰が積込みを行うかを必ず明記」→ 法定ではなく推奨（国交省書面例に「積込み作業の委託 有・無」欄あり）。
- 道交法58条の5 → 「過積載となるとの**情を知りながら**」引き渡す者が名宛人。過失では要件を欠く。
- 貨運法65条（荷主勧告）→ 事業者への命令・処分が前提で、事業者への処分だけでは再発防止が困難なときに「勧告することが**できる**」。
- 「巡回指導で必ず見つかる」→「見つかる可能性が高い」（Ⅰ-6は本社巡回に限る）。
- 23条の4「2回以内」→ 法文は「二以上の段階にわたる委託を制限するために必要な措置」。「2回以内」は国交省の説明。
- 「ゼッケンは白ナンバーでも取得できる」→ 3条1項は自家用にも届出＋指定申請を**義務づける**規定なので「付いている」。
- 「翌月末払い」は大の月で61〜62日目 → 公取委テキストは「2か月以内」運用で問題としない旨を明記。
- 利用運送約款の賠償基準 → 「引き渡すべきであった日の到達地の価額」（約款47条）。「引渡されるべき地及び時」は商法576条の文言。
- 変更登録の登録免許税1.5万円 → 財務省令で定めるものに限る。自動車のみの事業者の国内区域拡大は非課税（A13）。
- 元請連絡事項③請負階層・④管理簿対象である旨 → 法24条の5第2項の法定事項は①②のみ。③④はQ&A問4-7・リーフレットに基づく通知事項。
- 岩手県の産廃再委託 → 「公表資料で確認できなかった」は言い過ぎ。県の手引に法令どおりの要件の記載はあり、緊急時限定等の運用方針の記載はない。
- 盛土規制法 → 運搬の規制ではなく、搬入先の盛土工事が規制区域内なら工事主に許可が必要。

## 4. 変わらなかった結論

1. 有限会社石名坂商事に第一種貨物利用運送事業の登録は不要。必要なのは事業計画変更認可（⑥のみ。1〜4か月。非課税）。
2. 株式会社石名坂は登録不要と解され、かつ取るべきでない。
3. 白ナンバー（沢口砂利店・熊谷砂利店）への委託は65条の2違反（100万円以下の罰金・両罰）。
4. 砕石は有価物で、廃棄物処理法の再委託規制はかからない。
5. 引取販売への組み替えは、真正な売買（所有権移転・運送費負担・与信・価格決定権が買主側）である限り自家輸送として適法。買い戻しは違法。
