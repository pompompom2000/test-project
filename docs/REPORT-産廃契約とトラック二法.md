# 第1部：結論

## 1-1. 三行サマリ

### ① 許可は「重畳」する。互いに代替しない

産廃収集運搬業許可（廃掃法）、一般貨物自動車運送事業許可（貨運法＝緑ナンバー）、貨物利用運送事業の登録／許可は、**それぞれ独立に必要性が判断されます。** どれか一つを持っていても他を免れません。

### ② 「利用運送」は廃掃法の世界に存在しない

排出事業者から運搬を受託した者は、実際に運ぶかどうかに関係なく廃掃法上は**「運搬受託者」**です。他社に運ばせれば**定義上そのまま「再委託」**（原則禁止）、契約名義だけ立てれば**「名義貸し」**（最高5年＋許可取消し）。

**→ 利用運送モデルを産廃に持ち込むと、再委託違反か名義貸しのどちらかに必ず落ちる構造です。**

### ③ 2026年4月に「荷主＝排出事業者」側の刑事リスクが立ち上がった

無許可（白ナンバー）事業者への有償運送委託が明確に禁止され、**委託した荷主・元請にも100万円以下の罰金＋社名公表**。従来「運んだ側だけの問題」だった白トラ問題が、**排出事業者自身のリスク**になりました。

## 1-2. 最も危険な形態

**「他の産廃業者から運搬だけを請け負う（下請け・傭車）」形態は、二つの法律で同時にアウトになります。**

| 法律 | 違反 | 罰則 |
|---|---|---|
| **貨運法** | 収集も処分も伴わない運搬のみ＝無許可の有償運送 | 3年以下の拘禁刑 または 300万円以下の罰金 |
| **廃掃法** | 排出事業者と直接契約していない＝**再委託**（第14条第16項） | 3年以下の拘禁刑 または 300万円以下の罰金 |

さらに契約名義だけ立てるなら**名義貸し（最高5年＋許可取消し）**。

> 2026年4月以降は、**貨運法側の実運送体制管理簿によって多層構造が書面上可視化され、それがそのまま廃掃法上の再委託違反の証拠になり得ます。**
> 逆に言えば、**管理簿と委託契約書・マニフェストの整合性チェックが新たな内部監査項目**になります。

## 1-3. 適法な代替設計：区間委託

**排出事業者が、各区間を担当する収集運搬業者と、それぞれ直接二者間契約を締結する。**

元請運送事業者を介して階層構造を作るのではなく、**排出事業者が各運搬業者と横並びで直接契約する**点が決定的な違いです。**貨運法・廃掃法を同時にクリアする唯一の正攻法**です。

# 第2部：大前提 — 同じ言葉が法律ごとに別物を指す

ここを混ぜると設計を誤ります。**本件でいちばん重要な整理です。**

## 2-1. 「元請」の三義

| 法律 | 用語 | 誰を指すか | 負う義務 |
|---|---|---|---|
| **廃掃法** 🟡第21条の3第1項 | 元請業者 | 発注者から**直接建設工事を請け負った者**（ゼネコン等） | **排出事業者**となる。委託基準、マニフェスト交付 |
| **建設業法** 🟡第2条第5項 | 元請負人 | 下請契約における注文者で建設業者であるもの | 一括下請負の禁止（第22条）、実質的関与 |
| **貨運法**（2024年改正） | **元請運送事業者** | **荷主から運送を引き受けた運送事業者** | 実運送体制管理簿の作成・保存、書面交付 |

> **ゼネコンは①②の名宛人だが、③ではありません**（運送事業者ではないため）。貨運法上ゼネコンは「**荷主**」の側です。
> 逆に**産廃収集運搬業者は③になり得るが①ではありません。**
> 「うちは元請だから実運送体制管理簿を作る側だ」は典型的な誤解です。

## 2-2. 「荷主」の三義

| 法律 | 用語 | 定義の軸 |
|---|---|---|
| **廃掃法** | （荷主概念なし）**排出事業者** | 廃棄物を排出した事業者。建設工事では元請 |
| **貨運法** 🟡第64条（2025年4月以降 第65条か） | 荷主 | 運送を依頼した者。違反原因行為をした場合に勧告・公表 |
| **物流効率化法**（2024年改正） | **第一種荷主（主に発荷主）／第二種荷主（主に着荷主）**、一定規模以上は**特定荷主** | 貨物の**運送契約の有無**で区分 |

## 2-3. 「利用運送」

- **貨物利用運送事業法上**：他の運送事業者の実運送を利用しつつ、**自己の名で荷主に対し運送責任を負う**事業。第一種＝登録／第二種＝許可（🟡第3条・第20条とされるが未確認）
- **廃掃法上**：**概念として存在しません。** → 第6部参照

# 第3部：産廃処理委託契約の骨格（廃棄物処理法）

## 3-1. 排出事業者責任

| 🟡条文 | 内容 |
|---|---|
| 法第3条第1項 | 事業者は事業活動に伴い生じた廃棄物を**自らの責任において適正に処理**しなければならない |
| 法第11条第1項 | 事業者は、その産業廃棄物を**自ら処理**しなければならない（自己処理原則） |
| 法第12条第5項 | 委託する場合、運搬は**産業廃棄物収集運搬業者**に、処分は**産業廃棄物処分業者**に、**それぞれ**委託 |
| 法第12条第6項 | 委託の際は**政令で定める基準（委託基準／令第6条の2）**に従う |
| 法第12条第7項 | 委託後も、**最終処分終了までの一連の行程**の適正処理確保に必要な措置を講ずる努力義務 |

**「委託しても責任が残る」構造**：委託は自己処理の例外にすぎず、処理責任そのものは移転しません。これを制度的に担保するのがマニフェストと措置命令です。

## 3-2. 委託基準の要点

1. **許可業者への委託義務** — 単に許可を持つだけでは足りず、**許可の「事業の範囲」（廃棄物の種類・処分方法）に合致**していること。収集運搬業許可は**積込み地と荷卸し地の双方の自治体分**が必要
2. **書面による契約**
3. **二者間契約の原則** — 排出事業者⇔収集運搬業者／排出事業者⇔処分業者 を**別個に締結**。**三者契約は原則として認められません**
   - 趣旨：①排出事業者が処分業者の能力を自ら確認すること、②**金銭の流れを透明にし、各業者に適正な料金が渡ることを担保**すること（＝丸投げ・ピンハネの防止）
4. **許可証の写しの添付** — 有効期限内であること、契約書の事業範囲と一致していることを確認
5. **契約書・添付書面を契約終了の日から5年間保存**（起算点は締結日ではなく**終了日**）

## 3-3. 契約書の法定記載事項

**🟡政令で定める事項**（令第6条の2第4号）
- 委託する産業廃棄物の**種類及び数量**
- 運搬委託のときは**運搬の最終目的地の所在地**
- 処分・再生委託のときは**その場所の所在地、方法、施設の処理能力**
- 中間処理される場合は**最終処分の場所の所在地、方法、施設の処理能力**

**🟡環境省令で定める事項**（規則第8条の4の2）
- 契約の**有効期間**／支払う**料金**／受託者の**許可の事業の範囲**
- 積替え保管を行う場合の**場所の所在地、保管できる種類、保管上限**
- **適正処理に必要な情報**（性状・荷姿、性状変化、混合による支障、石綿含有／水銀使用製品産業廃棄物の別 等）
- 情報に変更があった場合の**伝達方法**／**業務終了時の報告**／**契約解除時の取扱い**

### 【2026年1月1日施行】化管法関係の追加

委託者が化管法上の**第一種指定化学物質等取扱事業者**であり、委託する産廃に第一種指定化学物質が含まれ／付着している場合、**その旨と当該物質の名称・量または割合**を契約書に記載。

（令和7年4月22日公布・令和8年1月1日施行。施行時の既存契約は**契約更新までは旧規定適用**）

> **本日時点で既に施行済みです。新規・更新契約では対応が必須です。**

## 3-4. 再委託の原則禁止（🟡法第14条第16項）

産廃収集運搬業者・処分業者は、**委託を受けた処理を他人に委託してはならない。**

例外要件（🟡令第6条の12、規則第10条の7）をすべて満たす場合のみ：

1. **排出事業者からあらかじめ書面による承諾**（口頭不可。承諾書の写しを5年間保存）
2. 再受託者が**許可業者**であり、事業の範囲に当該廃棄物が含まれる
3. **書面による委託契約**
4. マニフェストの適正運用

> 想定されているのは**車両故障・事故等の緊急時の一度限りの措置**であり、**恒常的なビジネスモデルとしての利用は想定されていません。**
> なお**一般廃棄物には再委託の例外規定が一切ありません**（全面禁止）。

## 3-5. マニフェスト

| 票 | 意味 | 返送期限（交付日から） |
|---|---|---|
| B2票 | 運搬終了報告 | **90日以内**（特管産廃 60日） |
| D票 | 処分終了報告 | **90日以内**（特管産廃 60日） |
| E票 | **最終処分**終了報告 | **180日以内** |

- A票および返送票を**5年間保存**
- 期限内に返送がない場合、処理状況を把握し、必要な措置を講じ、**30日以内に都道府県知事等へ措置内容等報告**
- **電子マニフェストの一部義務化**（2020年4月〜）：前々年度の特別管理産業廃棄物（PCB廃棄物を除く）の発生量が**年間50トン以上**の事業場

**運搬受託者欄には誰を書くか**
- 原則：**実際に運搬する者**
- **区間委託の場合**：**区間ごとに分けて、それぞれの運搬受託者を記載**
- **例外的再委託の場合**（東京都Q&A）：運搬受託者欄には**再委託先収集運搬業者**を記入し、当初の委託先収集運搬業者名を**「追加記載事項」欄**に記入することを原則とする
- ❌ 「利用運送事業者を運搬受託者欄に書いて実運送業者を書かない」運用は、**虚偽記載（1年以下・100万円以下）＋名義貸しの両方を疑わせます**

## 3-6. 罰則

| 行為 | 罰則 |
|---|---|
| 産廃収集運搬業の**無許可営業** | **5年以下の拘禁刑 もしくは 1,000万円以下の罰金 または併科**。法人は**3億円以下**（両罰規定） |
| **無許可業者への委託（排出事業者側）** | **5年以下 もしくは 1,000万円以下 または併科** 🔴解説間で記述が割れており要確認 |
| **名義貸し**（🟡法第14条の3の3） | **5年以下**。加えて**許可取消し**（欠格要件を通じて他自治体・他事業の許可まで連鎖的に失う） |
| **再委託禁止違反** | **3年以下 もしくは 300万円以下 または併科** |
| マニフェスト不交付・虚偽記載・保存義務違反 | **1年以下 もしくは 100万円以下** |

※ 令和7年6月1日施行の刑法改正により「懲役」は「**拘禁刑**」に置き換わっています。

### 措置命令による排出事業者への遡及（🟡法第19条の6）

処理業者に資力がなく支障除去が困難な場合、**委託契約書・マニフェストの取扱いが適正だった排出事業者でも**、①**適正な処理料金を負担していない**、②**不適正処理を知り、または知り得た**等の「責めに帰すべき事由」があれば、**支障除去の措置命令（＝原状回復費用負担）の対象**になります。

> **形式的コンプライアンスだけでは免責されません。相場から著しく乖離した安値契約は危険です。**

# 第4部：「トラック二法」は3世代ある

**この用語は文脈判定が必須です。**

## (A) 1990年施行の「物流二法」＝ 狭義のトラック二法

| 項目 | 内容 |
|---|---|
| 構成法 | **貨物運送取扱事業法**（平成元年法律第82号）＋ **貨物自動車運送事業法**（平成元年法律第83号） |
| 公布 | 1989（平成元）年12月19日 |
| 施行 | **1990（平成2）年12月1日** |

- 道路運送法から貨物部門を分離独立、通運事業法を廃止
- **免許制 → 許可制**、**運賃の認可制 → 事前届出制**（経済的規制緩和）。安全規制は強化
- → 新規参入が急増し、**運賃低迷・多重下請構造の温床**になったというのが、2024年以降の再規制の背景
- 貨物運送取扱事業法は平成14年改正（2003年4月1日施行）で**「貨物利用運送事業法」に改称**。同時に**運送取次事業の規制は廃止（自由化）**

> 「平成2年物流二法」と施行年で呼ぶのが一般的ですが、**法令番号は「平成元年法律第82号／第83号」**です。

## (B) 2024年成立の「改正物流二法」＝ 物流関連二法

| 項目 | 内容 |
|---|---|
| 法律名 | 流通業務の総合化及び効率化の促進に関する法律**及び**貨物自動車運送事業法の一部を改正する法律 |
| 法令番号 | **令和6年法律第23号** |
| 公布 | 2024年5月15日 |
| 施行 | **2025年4月1日 ／ 2026年4月1日 の二段階** |

改正対象の「二法」＝ ①**流通業務総合効率化法**（→ 改正で法律名自体が**「物資の流通の効率化に関する法律（物流効率化法）」に変更**）＋ ②**貨物自動車運送事業法**

> ⚠️ **(A)は「2本の新法」、(B)は「1本の改正法が2本の法律を改正するもの」。構造が全く違います。**
> ⚠️ **(B)には貨物利用運送事業法は直接含まれていません。**

## (C) 2025年成立の「トラック適正化二法」— 見落とされがちな第三の二法

# 第5部：貨物利用運送事業法の構造

## 5-1. 「利用運送」の定義

**他人の需要に応じ、有償で、自らが運送主体（荷主に対し運送責任を負う）となって、実運送事業者の行う運送を利用して行う貨物の運送**

**キーは「自らの運送責任において」。**

| | 利用運送 | 運送取次 |
|---|---|---|
| 契約の性質 | 荷主と**運送契約（請負）**を締結 | 荷主と実運送事業者の**仲介（委任）** |
| 荷主への運送責任 | **負う** | **負わない** |
| 規制 | **登録／許可が必要** | **不要**（2003年4月1日に規制廃止） |

## 5-2. 第一種と第二種

| | 第一種貨物利用運送事業 | 第二種貨物利用運送事業 |
|---|---|---|
| 参入規制 | **登録** | **許可** |
| 利用モード | 船舶・鉄道・航空・**自動車**のいずれか単一モード | **幹線（船舶・鉄道・航空）＋前後の自動車集配**を一貫 |
| 事業形態 | 単純な利用運送 | ドア・ツー・ドアの複合一貫輸送 |

> **第二種に「自動車利用」は存在しません。** 自動車のみを利用する場合は必ず第一種です。

## 5-3. 混同注意：「貨物自動車利用運送」と「第一種貨物利用運送事業」は別制度

- **一般貨物自動車運送事業者**が自らの運送責任のもとで他のトラック事業者を使う場合 → **貨運法上の「貨物自動車利用運送」**として、**事業計画に記載**して行う
- 実運送事業を持たない者が利用運送を行う場合 → **貨物利用運送事業法の第一種登録**

## 5-4. 「水屋」

自社車両を持たず荷物と車両をマッチングする仲介業者の業界俗称。法的には
- **運送責任を負う** → 貨物利用運送事業（**登録／許可が必要**）
- **運送責任を負わない純粋な仲介** → 運送取次事業（規制なし）

**登録・許可なく運送責任を負って手配すれば無登録営業**になる点が実務上の最大リスクです。

# 第6部：交点① — 利用運送は産廃に使えない

## 6-1. なぜ使えないのか（廃掃法の条文構造から）

### ① 委託基準（🟡法第12条第5項）

排出事業者が運搬を委託できる相手は**「産廃収集運搬業許可を持つ者」のみ**。**貨物利用運送事業者であることは廃掃法上まったく無関係**です。

利用運送事業者が排出事業者から運搬を引き受けるなら、**その事業者自身が産廃収集運搬業許可を持っていなければ、排出事業者が委託基準違反**。

### ② 再委託禁止（🟡法第14条第16項）

利用運送の本質は「自分は運ばず、実運送事業者に運ばせる」こと。これは廃掃法上、**定義上そのまま「再委託」**です。

### ③ 名義貸しの禁止（🟡法第14条の3の3）

「許可業者Aが契約名義だけ立てて、実際はBに運ばせる」は名義貸し。**廃掃法で最も重い部類の罰則（最高5年）＋許可取消し**。取消しは欠格要件を通じて**他自治体・他事業の許可まで連鎖的に失う**ため、事業存続に直結します。

> **→ 利用運送モデルを産廃に持ち込むと、再委託違反か名義貸しのどちらかに落ちる構造です。**
> **これは許可の有無の問題ではなく、契約構造の問題です。**

## 6-2. 両者が許可を持っていても壁は残る

| 当事者 | 廃掃法上必要なもの | 貨運法・利用運送法上必要なもの |
|---|---|---|
| **利用する側**（排出事業者から受託） | **産廃収集運搬業許可が必要**。かつ自ら運搬しないなら再委託禁止に抵触 | 第一種貨物利用運送事業の登録等。2026年4月から実運送体制管理簿等の義務も適用拡大 |
| **実際に運ぶ側**（実運送） | **産廃収集運搬業許可が必要**。かつ排出事業者と直接契約していなければ再委託に当たる | 有償運送に当たるなら貨運法第3条許可。適用除外の可否は第8部参照 |

## 6-3. ✅ 適法な代替設計：リスクの低い順

| 順 | 設計 | 備考 |
|---|---|---|
| 1 | **自社運搬** | 許可不要。ただし車体表示・書面備付け必須。**別法人はすべて「他人」＝NG** |
| 2 | **単一の許可業者への直接委託** | 最も単純。二者間契約＋マニフェスト |
| 3 | **区間委託** | 排出事業者が各区間の許可業者と**それぞれ直接二者間契約**。**利用運送的運用の適法な代替** |
| 4 | **積替保管経由** | 一次運搬業者・積替保管業者・二次運搬業者それぞれと契約 |
| 5 | **親子会社間** | 🟡廃掃法第12条の7の**一体的経営の認定**を取得すれば自社処理扱い。認定番号を車両両側面に表示、認定書写しを車両に備付け |
| 6 | **例外的再委託** | 緊急時のみ。事前書面承諾＋再委託基準遵守。**恒常運用不可** |
| ❌ | **利用運送モデル** | **恒常的には廃掃法上不可** |

# 第7部：交点② — 荷主＝排出事業者への義務の重畳

排出事業者が同時に貨運法上の「荷主」であり物流効率化法上の「荷主」でもある場合、以下が**重なって**かかります。

| 局面 | 廃掃法（排出事業者として） | 貨運法（荷主として） | 物流効率化法（荷主として） |
|---|---|---|---|
| **委託先の選定** | **産廃収集運搬業許可の確認**。違反は5年以下・1,000万円以下 | **2026年4月〜：無許可（白ナンバー）事業者への有償運送委託の禁止。100万円以下の罰金＋社名公表** | — |
| **契約** | **書面による委託契約**（法定記載事項） | **運送契約の書面交付義務**（2025年4月〜） | — |
| **運行中の負荷** | — | **荷主勧告／働きかけ・要請**：長時間の荷待ち、無理な運行指示等 | **荷待ち・荷役時間短縮の努力義務**（2025年4月〜、全荷主） |
| **体制** | 処理状況の確認努力義務 | — | **特定荷主なら CLO選任・中長期計画・定期報告**（2026年4月〜） |
| **記録** | **マニフェスト**、交付等状況報告 | 実運送体制管理簿は元請**運送事業者**の義務（荷主は**閲覧請求権**を持つ側） | 定期報告 |

## 7-1. 委託先確認が二重になった（2026年4月〜）

排出事業者は**「廃掃法の産廃収集運搬業許可」**と**「貨運法上の適法性（緑ナンバー、または適用除外に当たること）」**の**両方**を確認する必要があります。**前者だけの確認では貨運法側の罰則リスクが残ります。**

## 7-2. 実運送体制管理簿（2025年4月1日施行）

- **🟡根拠**：貨運法 第24条の5第1項
- **義務者（＝元請事業者）**：**真荷主から引き受けた貨物**の運送について、**他の貨物自動車運送事業者の運送を利用した**一般貨物自動車運送事業者
- **対象貨物の重量要件**：**1.5トン以上**。判定は「**真荷主から依頼があった時点の重量**」
- **記載事項**：実運送事業者の**名称**、**請負階層（何次下請にあたるか）**等
- **保存**：営業所に備え置き、**運送完了日から1年間**
- **通知義務**：元請以外の各事業者は、管理簿作成に必要な情報を元請事業者に**通知する義務**
- **真荷主の閲覧請求権**：真荷主は元請事業者に管理簿の**閲覧を請求できる**

## 7-3. 書面交付義務（2025年4月1日施行、🟡貨運法第12条）

運送契約締結時に、以下を**書面に記載して相互に交付**：
- 運送の役務の内容および**その対価（運賃）**
- **附帯業務**が含まれる場合はその内容および対価
- **その他特別に生ずる費用に係る料金**（高速道路利用料、燃料サーチャージ、待機時間料等）
- 契約当事者の氏名・名称および住所

電磁的方法による提供可（相手方の承諾を得た場合）。**写しを1年間保存**。

## 7-4. 健全化措置／運送利用管理規程・運送利用管理者（2025年4月1日施行）

- **健全化措置の努力義務**：委託先（下請）事業者の健全な事業運営の確保に資する取組
- **「特別一般貨物自動車運送事業者」**＝ 貨物自動車利用運送に係る取扱貨物重量が**前年度100万トン以上**の一般貨物自動車運送事業者
  - **運送利用管理規程の作成・国土交通大臣への届出**
  - **運送利用管理者の選任**（事業運営上の重要な決定に参画する管理的地位にある者から1名）
  - 職務に**実運送体制管理簿の作成の監督**を含む
  - 届出期限：100万トン以上となった事業年度の**翌年度の7月10日まで**

## 7-5. 2026年4月1日施行分（主に令和7年法律第60号）

1. **貨物利用運送事業者（第一種・第二種）への適用拡大** — 書面交付義務・実運送体制管理簿・運送利用管理規程・運送利用管理者の各義務が利用運送事業者にも準用
2. **再委託回数の制限** — **再委託2回以内（＝実運送は3次請けまで）の努力義務**。管理責任は**元請事業者**
3. **違法な「白トラ」規制の強化** — 白ナンバー車両で有償貨物運送を行う無許可事業者に**運送委託した荷主等も処罰対象**（**100万円以下の罰金＋社名公表**）。要請・勧告・命令の行政プロセスも整備され、勧告段階で社名公表の可能性

# 第8部：交点③ — 産廃運搬に緑ナンバーは要るか

## 8-1. 【重要な訂正】「解釈の対立」は存在しなかった

調査の途中段階で、適用除外の範囲について「広い読み方（環境省系）と狭い読み方（国交省系）が対立している」と整理しましたが、**これは誤りでした。**

いわゆる「狭い読み方」（**自ら処理施設を有して処分まで行う場合に限る**）は、**2026年3月16日事務連絡より前の「従来の整理」**です。事務連絡はそれを**明確化・拡張**したものであり、対立する二つの解釈ではなく**時間的に前後する新旧の基準**でした。

解説記事が背景として従来の整理を先に述べ、そのうえで新事務連絡を紹介する構成を取っているため、調査の初期段階でこれを取り違えていました。弁護士 猿倉健司氏（牛島総合法律事務所）も本事務連絡を**「許可が不要となる場合の範囲を拡大するもの」**と整理しています。

## 8-2. 🟡 事務連絡の核心部分（原文と推定される文言）

> 廃棄物処理業者が、発注者である市町村や排出事業者と締結した**包括的な委託等契約**に基づき、**廃棄物の運搬と、その他の廃棄物の処理（収集又は処分）を一体的に実施する場合**において、当該委託等契約に基づく業務の一環として行われる運搬行為については、**自己の生業である廃棄物処理業務と密接不可分**であり、その業務に**付帯して行われる運送**であるため、法の許可等を要しないものと解されます。

> なお、運送にあたって、**収集又は処分を伴わない廃棄物の運搬行為のみを行う場合**には、法の許可等が必要となります。

## 8-3. 決定的なポイント：「収集**又は**処分」

事務連絡の文言は**「その他の廃棄物の処理（収集又は処分）」**です。

**「かつ」ではなく「又は」。** 括弧書きが「処理」の内容を **収集 or 処分** と定義しています。

**→ 収集さえ伴っていれば足り、処分施設を持っている必要はありません。**

### 廃掃法における「収集」と「運搬」は別概念

| 用語 | 意味 |
|---|---|
| **収集** | 排出場所（各戸・各現場・各事業所）を回って、廃棄物を**集める**行為 |
| **運搬** | 集めた廃棄物を、保管場所・積替場所から**別の場所（処分場等）へ運ぶ**行為 |

ごみ収集車が住宅街を巡回してごみステーションを回る行為が「収集」、満載後に清掃工場へ走る行為が「運搬」です。

### 従来の整理との比較

| | 従来の整理（〜2026年3月15日） | 2026年3月16日事務連絡 |
|---|---|---|
| **判断軸** | **自ら処理施設を有し、処分まで行う**か | **包括的な委託等契約**に基づき、運搬と**収集又は処分**を一体実施しているか |
| 典型的に許可不要 | 中間処理業者・最終処分業者が**自社の事業場へ**運び込む場合／排出事業者の自社運搬 | 上記に加え、**市町村・排出事業者から包括受託して収集＋運搬を行う収集運搬専業者** |
| 収集運搬専業者 | ❌ 対象外になり得た | ✅ **対象に入る** |

## 8-4. 本当の分岐線は「契約構造」

適用除外の3要件：

| # | 要件 | 内容 |
|---|---|---|
| ① | **契約の主体** | 発注者が**市町村または排出事業者**であること |
| ② | **契約の性質** | **包括的な委託等契約**であること（運搬だけを切り出した契約ではない） |
| ③ | **業務の一体性** | 運搬と、**収集または処分**を**一体的に実施**していること |

### 🔑 料金体系が事実認定を左右する

処理料金が**運搬と処分を含む包括料金**として設定されている場合、**「運送の対価」とは見なされない**とされています。

逆に、**請求書上で「運搬費」を独立した対価として切り出している**と、その部分が「有償運送」と認定されるリスクが生じます。

## 8-5. ⚠️ 事務連絡の法的性質

事務連絡は**法令でも告示でもなく、行政内部の連絡文書**です。行政側の解釈の表明にとどまり、**司法判断を拘束しません。** グレーな事業形態については、**地方運輸局 貨物課への事前照会**を推奨します。

| 以降 | 全国清掃事業連合会が適用除外の要望書を作成。環境省に対し、**貨運法の許可の有無は廃掃法上の委託・許可の要件とされていない**ことを確認 |
| 2026年3月16日 | **国交省・環境省が同日付で事務連絡を発出し、取扱いを明確化** |

> 環境省所管の廃掃法と国交省所管の貨運法が、**同じ行為に別々の許可制度を重ねてきた**ことが問題の根でした。2026年4月の白トラ規制強化で「荷主＝市町村・排出事業者にも罰則」が及ぶことになり、**市町村自身が刑事リスクを負いかねない**状況になったため、決着が必要になったという経緯です。

# 第9部：ケース別判定 — 白ナンバーで営業できる例／できない例

## 9-1. 前提：許可の要件にナンバー種別は入っていない

**産業廃棄物収集運搬業許可の申請において、車両のナンバー種別（白／緑）は審査対象ではありません。**

車両側の要件は主に次の点です。
- 車検証の有効期間が申請日時点で有効であること
- **車検証の使用者が許可申請者本人**であること（社長個人名義の車では法人の許可は下りない）
- ⚠️ **他者が貨物運送事業に使用している緑ナンバー車両の賃貸借による登録は原則不可**

→ 論点は「許可が取れるか」ではなく、**「許可取得後、白ナンバーのまま営業して貨運法違反にならないか」**です。

## 9-2. ✅ 白ナンバーで営業できる例

| # | ケース | なぜOKか |
|---|---|---|
| 1 | **建設現場で発生した産廃を収集し、委託契約に定められた処分施設まで運搬** | 元請（＝排出事業者）と直接の包括的処理委託契約。現場で**収集**を伴う |
| 2 | **オフィスビル・店舗・工場を巡回して廃棄物を集め、中間処理施設へ運ぶ** | 排出事業者と直接契約。巡回して集める行為が**収集** |
| 3 | **市町村から家庭ごみの収集運搬を包括受託**（一般廃棄物） | 発注者が市町村。事務連絡が直接想定している類型 |
| 4 | **中間処理業者・最終処分業者が、自社の処理施設へ運び込む** | **従来の整理でも許可不要**だった類型 |
| 5 | **排出事業者が自ら排出した廃棄物を自社車両で運ぶ** | そもそも「他人の需要に応じ」ていない。**産廃収集運搬業許可自体も不要** |
| 6 | **解体業者が、自社が元請として施工した現場の廃棄物を運ぶ** | 元請＝排出事業者なので 5 と同じ |

**共通点**：①**排出事業者または市町村と直接契約**、②**包括的な委託契約**、③**収集または処分を伴う**。

## 9-3. ❌ 緑ナンバーが必要になる例

| # | ケース | なぜ必要か |
|---|---|---|
| 1 | **他の産廃業者から「運搬だけ」を下請け・傭車で請け負う** | 発注者が排出事業者でない。**廃掃法上も再委託でアウト** |
| 2 | **積替保管施設から処分場までの区間だけを、他社から受託して運ぶ** | 収集を伴わない運搬のみ |
| 3 | **運送会社が、産廃処理の「運搬部分」だけを切り出して請け負う** | 契約が運搬のみ。包括的委託契約でない |
| 4 | **有価物・資材・土砂・砂利などを有償で運ぶ** | そもそも廃棄物処理業務ではない |
| 5 | **有価物と廃棄物を混載し、有価物分の運賃を受け取る** | 有価物部分が有償運送に当たり得る |

## 9-4. 判定フロー

```
その運搬の発注者は誰か？
├─ 自社（自ら排出した廃棄物）      → 白ナンバーOK（許可も不要）
├─ 排出事業者 または 市町村
│   └─ 包括的な処理委託契約か？
│       ├─ YES → 収集または処分を伴うか？
│       │         ├─ YES → ✅ 白ナンバーOK
│       │         └─ NO（運搬のみ） → ❌ 緑ナンバー必要
│       └─ NO（運搬のみの契約） → ❌ 緑ナンバー必要
└─ 他の産廃業者・運送会社         → ❌ 緑ナンバー必要
                                    ＋ 廃掃法上も再委託違反の可能性
```

## 9-5. 🔑 白ナンバー運用を維持するための実務ポイント

1. **契約書を「収集・運搬・処分を含む包括的な処理委託契約」の形にする** — 運搬だけを切り出した契約書にしない
2. **料金を包括料金にする** — 請求書で「運搬費」を独立した対価として切り出すと、その部分が「運送の対価」と認定されるリスク
3. **排出事業者と直接契約する** — 他社を挟むと、貨運法・廃掃法の両方でアウトになる
4. **繁忙期の応援を安易に頼まない** — 他社に運搬だけ頼む／他社から運搬だけ請けるのが、最も陥りやすい違反パターン

# 第10部：建設廃棄物における元請・下請

## 10-1. 廃掃法第21条の3

- **🟡第1項**：建設工事が数次の請負によって行われる場合、**元請業者を事業者（＝排出事業者）とする。** 下請負人は自らが施工した工事から出た廃棄物であっても、排出事業者として処理・委託できません
- **🟡第2項**：下請負人は、許可規定の適用については事業者とみなさない（＝下請が建設廃棄物を運べば**無許可営業**）
- **🟡第3項（下請運搬の特例）**：以下をすべて満たす場合、**下請負人が収集運搬業許可なしに運搬できる**
  1. **維持修繕工事または新築後の瑕疵補修工事**（新築・増築・解体を除く）で、**請負代金が500万円以下**
  2. **特別管理産業廃棄物でない**
  3. **1回の運搬量が1m³以下**
  4. 運搬先が**同一都道府県内または隣接都道府県内**
  5. **積替え保管を行わない**
  6. **書面による請負契約で、下請負人が自ら運搬を行う旨が定められている**
  7. 運搬時に**請負契約書の写し＋廃棄物の種類・量・運搬先等を記載した書面を携行**

  > ⚠️ **本特例で下請ができるのは「運搬」のみ。処分は含まれません。**
  > ⚠️ 数量要件は「500kg」ではなく**「請負代金500万円以下」かつ「1回1m³以下」**です

- **🔴第4項**：下請負人が運搬・処分を**他人に委託する場合**は、下請負人を事業者とみなす。環境省は「**元請業者の倒産等の例外的な事例において適正処理を確保するための条文**」としています。本項の射程については解説間で記述が割れており、**特に要確認**

## 10-2. 建設業法第22条（一括下請負の禁止）との関係

- **第1項**：建設業者は、請け負った建設工事を、いかなる方法をもってするかを問わず、**一括して他人に請け負わせてはならない**
- **第3項**：重要な建設工事（政令で定めるもの）**以外**で、元請負人が**あらかじめ発注者の書面による承諾**を得たときは適用しない（民間工事の例外）
  - 🟡建設業法施行令第6条の3により、**共同住宅を新築する工事**は例外の対象外
- **公共工事は全面禁止**（入契法第14条により第22条第3項を適用しない）
- 判断基準は**「実質的関与」**の有無（施工計画作成、工程管理、品質管理、安全管理、技術的指導等）

### 混同しやすい点

- **廃棄物の収集運搬・処分の委託は「建設工事の請負」ではありません。** 元請が廃棄物処理を産廃業者に委託すること自体は建設業法第22条の一括下請負に当たりません
- 逆に、**解体工事そのものを丸投げすれば建設業法第22条違反**であり、かつ**廃掃法上の排出事業者責任は元請に残り続けます。「丸投げしたから責任も移った」ことにはなりません**

> **建設業法22条は「工事の丸投げ」を、廃掃法14条16項は「廃棄物運搬の丸投げ」を禁じており、規制対象が別です。両方に別個に引っかかり得ます。**

# 第11部：実務リスクと対応策

| リスク | 症状 | 対応 |
|---|---|---|
| **無許可運搬** | 積込み地／荷卸し地のいずれかの自治体の許可が欠けている／事業範囲に当該廃棄物が含まれない／積替保管の許可がないのに積替えをしている | **許可証の原本確認（有効期限・事業範囲・積替保管の有無・両自治体分）を契約締結時と更新時にルーチン化**。写しを契約書に添付 |
| **名義貸し** | 契約名義・マニフェスト記載と実際の運搬主体が違う／許可業者の車体表示を付けた他社車両が走っている | **車体表示・車検証使用者名義・許可申請時の登録車両の三者一致を実地確認**。抜き打ちの現場確認・写真記録 |
| **多重下請（＝産廃では即「再委託」）** | 「うちが元請で下請に流している」「利用運送で回している」という説明が出てくる | **契約構造を排出事業者との直接二者間契約に組み替える**（区間委託／積替保管を介した区間別契約） |
| **書面不備** | 法定記載事項の欠落／三者契約／再委託の書面承諾がない／マニフェストの運搬受託者欄が実態と不一致／貨運法の書面交付がされていない | 委託契約書のひな形を法定記載事項チェックリストで点検。**三者契約は原則として組まない** |
| **白ナンバー問題** | 委託先の産廃収集運搬業者が白ナンバー車両を使っている | 第8・9部の3要件で判定。廃棄物以外を運ばせている部分は**明確に緑ナンバーが必要**。社内規程・内部監査に**「委託先の車両ナンバー種別確認」**を追加 |

## 11-1. 棚卸しチェックリスト

- [ ] その運搬の**発注者は誰か**。市町村・排出事業者か、それとも**他の産廃業者**か
- [ ] 契約は**包括的な処理委託契約**の形になっているか。運搬だけを切り出した契約になっていないか
- [ ] 実際に**収集（排出場所を回って集める行為）を伴っている**か。積替保管施設から先だけを運んでいないか
- [ ] **料金が運搬と処分を含む包括料金**か。請求書上で「運搬費」が独立した対価として切り出されていないか
- [ ] **廃棄物以外（有価物・資材・土砂等）**を有償で運んでいる部分はないか
- [ ] 排出事業者側：委託先の**車両ナンバー種別の確認**を社内規程・内部監査項目に追加したか
- [ ] **実運送体制管理簿と、廃掃法の委託契約書・マニフェストの整合性**を確認したか

## 11-2. 自社運搬の境界

**排出事業者が自ら運搬する場合 ＝ 産廃収集運搬業許可は不要**（🟡法第14条第1項ただし書）

- 都道府県をまたぐ移動でも許可不要。**マニフェストの交付義務もなし**
- ただし**産業廃棄物処理基準（収集運搬基準）は適用**：
  - **🟡車体表示義務**（規則第7条の2の2）
    - 自社運搬：①産業廃棄物を収集運搬している旨、②**排出事業者の名称**
    - 許可業者：①＋②収集運搬業者の名称＋③**許可番号（下6桁）**
  - **書面の備付け（携帯）義務**
- ⚠️ **別法人はすべて「他人」です。** 100%子会社でも、法人が違えば「委託」となり許可が必要
  - **例外**：🟡廃掃法第12条の7の**「一体的な経営を行う者の認定」**（平成30年4月1日施行）

| J | **「利用の利用」禁止**が法律本文の明文か、通達・審査基準レベルの運用か | 国交省「貨物利用運送事業についてのQ&A」 |

# 付録：岩手県・盛岡市の場合

| | |
|---|---|
| **原則** | 岩手県知事の許可で、盛岡市を含む県内全域の収集運搬が可能 |
| **例外** | **盛岡市内に積替保管施設を置く場合は、盛岡市長の許可が必要**（盛岡市は中核市） |
| 申請先 | 盛岡市環境部廃棄物対策課（若園町分庁舎3階 / 019-626-3755） |
| 手数料 | 新規 81,000円（**盛岡市収入証紙**での納付） |
| 県の窓口 | 岩手県環境生活部 資源循環推進課 廃棄物対策担当（019-629-5388） |

積替保管を挟む形態を検討する場合、**県と市の両方**を確認する必要があります。
