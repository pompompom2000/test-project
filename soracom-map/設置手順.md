# 車両 現在地マップ 設置手順

既存の仕組み（Beam → GAS → 「現在地」シート）に、**地図で見るページ**を追加します。
追加費用は0円です。SORACOM側の設定は変えません。

```
GPSマルチユニット → Beam → GAS(doPost) → 「現在地」シート
                                              ↓ 1分ごとに読む
                    ブラウザ／スマホ ← GAS(doGet) 地図ページ
```

## 1. ファイルを追加する（約5分）

1. 「現在地」シートがあるスプレッドシートを開き、**拡張機能 → Apps Script**
2. 左の「ファイル」の **＋ → スクリプト**。名前を `地図表示` にして、`地図表示.gs` の中身をすべて貼り付ける
3. **＋ → HTML**。名前を **`map`**（`.html` は付けない）にして、`map.html` の中身をすべて貼り付ける
4. `地図表示.gs` の先頭にある `MAP_VIEW_KEY` を、閲覧用の合言葉に書き換える
   - Beam用の合言葉とは**別のもの**にしてください（例：英数字12文字以上）
5. 保存（Ctrl+S）

> ⚠ 既存の `コード.gs` に `function doGet` がすでにある場合は、どちらか1つにしてください（同じ名前の関数が2つあると動きません）。

## 2. 動作確認（エディタ上）

1. 上の関数選択で `testGetCurrentLocations` を選んで **実行**
2. 「実行ログ」に車両名と緯度・経度が出れば成功
   - `シートが見つかりません` と出る場合 → シート名が「現在地」か確認
   - lat / lon が null の場合 → シートの見出し名を確認（「緯度」「経度」または「緯度経度」）

## 3. 再デプロイ（URLを変えない方法）

1. **デプロイ → デプロイを管理**
2. 鉛筆マーク（編集）→ バージョン：**新バージョン** → デプロイ
   - 「新しいデプロイ」は選ばないこと（URLが変わってBeamが届かなくなります）

## 4. ページを開く

ウェブアプリのURL（Beamに設定した `https://script.google.com/macros/s/…/exec`）の末尾に、次を付けて開きます。

```
https://script.google.com/macros/s/…/exec?key=閲覧用合言葉
```

- スマホのホーム画面に追加しておくと便利です
- Beam用URLの `?key=…&car=…` とは別のURLです。Beam側の設定は触らないでください

## 画面の見方

| 表示 | 意味 |
|---|---|
| 🟢 緑 | 稼働中（30分以内に受信） |
| ⚪ 灰色 | 通信途絶（30分以上受信なし。エンジン停止・圏外・電池切れなど） |
| 🟡 黄（一覧のみ） | 位置不明（屋内・トンネルなどでGPSが取れていない） |

- 1分ごとに自動で更新されます（位置自体は端末の送信間隔＝10分ごとに変わります）
- 右上のボタンで「地図」と「航空写真」を切り替えられます（国土地理院の地図・無料）
- 「通信途絶」の判定時間は `MAP_STALE_MINUTES` で変更できます

## 会社ホームページに載せる場合

ページの中に次のタグを貼ると、地図を埋め込めます。

```html
<iframe src="https://script.google.com/macros/s/…/exec?key=閲覧用合言葉"
        width="100%" height="800" style="border:0"></iframe>
```

ただし、**一般公開のページに埋め込むと、誰でも車両の居場所が見えてしまいます**（合言葉もページのソースから読めます）。
盗難や社員のプライバシーの面から、**社内だけで見るページ**に置くことをおすすめします。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 「権限がありません」と出る | URLの `?key=` が `MAP_VIEW_KEY` と一致しているか確認 |
| 「読み込みに失敗しました」と出る | 手順2のテスト関数を実行して、エラー内容を確認 |
| 修正したのに反映されない | 手順3の「新バージョン」でデプロイし直す |
| 車両が地図に出ない | 一覧で「位置不明」になっていないか確認（屋外でテスト） |
