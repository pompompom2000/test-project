# 追い切りタイムを全頭取る方法を探した結果

## 結論

**netkeibaの全頭タイムは有料。抜け道は無い。**
ただし**検証には課金が要らない**。理由は後述。

## netkeiba：型を全部試した

`race.netkeiba.com/race/oikiri.html?race_id=...&type=N` の N を 0〜8 まで。

| type | 表示頭数 | 内容 |
|---|---|---|
| 0,1,2,4,5,6,7,8 | **馬番1-3のみ** | 日付・コース・馬場・乗り役・累計タイム・区間ラップ・併せ馬・脚色・短評・評価 |
| **3** | **全頭** | 評価文字と短い所見のみ。**タイムなし** |

2015年のレースでも2026年のレースでも、出るのは常に馬番1,2,3。
古いレースが無料開放される、ということもない。

ページ内の規定文:

> 提供範囲 — 中間調教 / 重賞・新馬戦：プレミアム・スーパープレミアム・マスターコース
> / 上記以外のレース：スーパープレミアム・マスターコース

> すべての中間調教を見る／続きはプレミアムサービス登録でご覧になれます。

提供元は**デイリースポーツ**（表内に明記）。

`db.netkeiba.com/horse/training.html?id=` も有料で、価格表だけが返る。

## 他の無料ソースを探した

| 候補 | 結果 |
|---|---|
| 日刊スポーツ | 追い切りはコラム記事のみ。データ表なし |
| デイリースポーツ（提供元） | 自社サイトの競馬欄に調教データ表が見当たらない |
| JRA公式 | 調教タイムの無料公開は確認できず |
| JRA-VAN DataLab | **有料だが調教データを正式提供**（SDK経由） |
| 競馬ブック | 調教が主力商品。有料 |
| 競馬ラボ | この環境から到達不可（接続リセット。相手側のIP遮断と思われる） |

## 検証には課金が要らない

**馬番1〜3は無料で全部出る。そして馬番は枠順抽選で決まる。**

調教の出来と馬番は独立なので、**馬番1-3は馬の無作為標本**になる。
「調教タイムは市場を超える情報を持つか」は1頭単位の問いなので、
無作為標本があれば答えられる。全頭は要らない。

唯一の偏りは枠番が内に寄ること。枠番は既に検証して不発因子なので
問題にならないし、必要なら共変量に入れればいい。

### 取得済み（パイロット）

`tools/collect/collect_oikiri_times.py` を作り、G1 114レースで実行。

- **342頭**、追い切り **1,793本**（1頭あたり平均5.2本）
- 累計タイムが取れた馬 341/342
- コース内訳: 栗坂753 / ＣＷ336 / 南Ｗ260 / 美坂230 / 美Ｗ103 ほか
- 馬場: 良1,246 稍259 重224 不5（坂路は馬場表記なしで59本）

取れる形:
```json
{"date":"2015/09/29","course":"栗坂","baba":"",
 "cum":["62.9","45.7","29.3","14.2"],
 "lap":["17.2","16.4","15.1","14.2"],
 "drive":"馬也","best":false}
```

### 規模の見積もり

G1だけでは342頭で足りない。JRAは年間およそ3,400レースあるので、

| 期間 | レース数 | 取れる頭数 | 取得時間（0.9秒間隔） |
|---|---|---|---|
| 1年 | 約3,400 | 約10,200 | 約51分 |
| 3年 | 約10,200 | 約30,600 | 約2時間35分 |

着順との突合には既存のレース結果収集（`kyoto2000.py` の find/fetch と同じ形）が要る。

## 限界

- **運用には使えない。** 今日のレースを買うには全頭のタイムが要る。
  馬番1-3だけでは買い目が作れない。
- だから手順はこうなる：**無料の標本で「効くか」を先に判定し、
  効くと分かった場合にだけ課金を検討する。**
  評価文字での検証（`oikiri.md`）は不発だったので、
  タイムでも不発なら課金する理由は無い。
- 評価文字はデイリースポーツの編集判断で、タイムから人が作ったもの。
  タイムに評価文字以上の情報が残っているかは未知。
