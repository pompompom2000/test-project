# 完成イメージ作成チーム（Blender）　市道二子沢線道路改良工事

盛岡工業高校 土木科のインターン生2名が、Blender を使って工事の完成イメージを作るためのチーム編成と進め方をまとめたものです。図面から作った「たたき台モデル」を用意してあるので、生徒はゼロから作るのではなく、**図面と照らし合わせながらモデルを直して仕上げていく**ことに時間を使えます。

## チーム編成

| 役割 | 担当 | 主な仕事 |
|---|---|---|
| チームリーダー（メンター） | 施工管理の社員 | 図面の読み方を教える、出来上がりを図面で確認する、発表の講評 |
| 技術サポート | ICT・CAD 担当の社員（いなければ若手社員） | Blender の操作を教える、PC の準備、困ったときの相談役 |
| モデリング班 | 生徒A | **道路・構造物**：舗装、側溝、ボックスカルバートと面壁、ガードレール、視線誘導標 |
| 景観・演出班 | 生徒B | **地形・水路・見せ方**：地形、かごマット・ふとんかご、水面、樹木、空と太陽、カメラ、レンダリング |

- 2人で別々の部分を担当し、1日の最後に1つのファイルにまとめます。担当範囲は Blender のコレクション（下の表）で分けているので、作業がぶつかりません。
- 発表では、生徒Aが「図面をどう読んでモデルにしたか」、生徒Bが「完成イメージの見どころ」を話します。

| コレクション | 担当 | 中身 |
|---|---|---|
| 01_道路 | A | 新設舗装、既設舗装、サイドライン、第16・17号進入路 |
| 02_排水構造物 | A | U型側溝、落蓋式側溝、ボックスカルバート、第4・5号面壁 |
| 03_安全施設 | A | ガードレール Gr-C-4E（右25m・左77m）、視線誘導標 |
| 04_水路 | B | 第1・2号水路舗装工（かごマット・ふとんかご）、水面 |
| 05_地形 | B | 地形、法面（種子散布） |
| 06_樹木 | B | 杉・広葉樹 |

## 3日間スケジュールへの組み込み

| 日 | 時間 | 内容 |
|---|---|---|
| 1日目 | 午後（現場見学のあと） | 図面の読み方（平面図・縦断図・横断図・構造図）。そのあと Blender の基本操作（視点の回し方、選択、移動、カメラ）を1時間 |
| 2日目 | 午後（測量実習のあと） | 担当ごとにモデルを直す（下の課題）。雨天時は1日中これに充てる |
| 3日目 | 午前 | 2人の作業を1つにまとめてレンダリングし、発表スライドを作る |
| 3日目 | 13:00 | 成果発表会で、図面と完成イメージを並べて説明する |

## 課題の例（たたき台から精度を上げる）

**生徒A（道路・構造物）**
1. 縦断図と見比べて、計画高 FH の値が合っているか確かめる（スクリプト冒頭の `FH`）
2. 標準横断図から舗装の層（表層4cm、上層路盤10cm、下層路盤10cm、凍上抑制層25cm）を断面で見せる
3. 構造図を見ながら、ボックスカルバートの面壁を段のある正しい形に直す
4. 安全施設工の図から、ガードレールのビームと支柱の高さを図面どおりにする

**生徒B（地形・水路・見せ方）**
1. 横断図（NO.50〜NO.59）と見比べて、法面と水路の形を直す
2. かごマットを3段積・4段積の区間に分け、図面どおりの延長にする
3. 季節（新緑・紅葉・雪）を選んで、空、太陽の向き、木の色を変える
4. 地元の人に見せるならどの角度がよいかを考えて、カメラを1台追加する

## たたき台モデルの使い方

1. Blender 4.2 以降をインストールする（無料。**今日中にインストールしておく**）
2. `futagosawa_kansei.blend` を開く。または Scripting タブで `futagosawa_kansei.py` を開いて「▶ Run Script」で作り直す
3. カメラは4台あります：`CAM_01_鳥瞰`、`CAM_02_ドライバー視点`、`CAM_03_水路側から`、`CAM_04_函渠付近`
4. 画像を出すとき：レンダー → 画像をレンダリング（F12）

コマンドラインで全カメラの画像を出す場合：
```
blender -b -P futagosawa_kansei.py -- --render          # renders/ に4枚出力
blender -b -P futagosawa_kansei.py -- --render --fast   # 低画質で試す
```

## 図面から入れた値・簡略化したところ

- **入れた値**
  - 施工延長190.07m（NO.50〜NO.59+10.07）、幅員5.0m、横断勾配2%
  - 曲線区間 BC-9〜EC-9（半径は約110mと読み取った値）
  - 計画高 FH（NO.50〜NO.60）
  - 側溝の種類・延長・左右
  - ボックスカルバート B1200×H1000（L=23.15m、斜角約60°）
  - 面壁（幅6.0m、高さ2.5m）
  - ガードレール（右25m、左77m）、視線誘導標13本
  - 進入路2か所
- **簡略化したところ**
  - 地形と水路の位置は、横断図を参考にした「それらしい形」です。現況の地形データではありません。
  - 面壁の段の形、かごの段数の区間、樹木は簡略化しています（課題で直す部分です）。
- 元の資料は、盛岡市建設部道路建設課の入札時積算参考資料です。そのため完成イメージは**社内・インターン用**とし、外部に出す前に発注者の確認を取ってください。
