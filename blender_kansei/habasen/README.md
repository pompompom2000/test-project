# 完成イメージ作成チーム（Blender）　市道羽場線外２路線道路改良工事

この工事は、盛岡市内の3か所を1件として発注するものです（令和8年度、盛岡市建設部道路建設課、工期217日間）。

`habasen_kansei.py` を使うと、1本のスクリプトで3か所それぞれの完成イメージを作れます。図面の読み取りはすでに済ませてあり、結果は下の「図面から入れた値」にまとめています。チームの仕事は、このたたき台を**図面と照らし合わせて確かめ、直し、見せ方を仕上げる**ことです。

## チーム編成

| 役割 | 担当 | 主な仕事 |
|---|---|---|
| 総括（リーダー） | 施工管理の社員 | 3か所の優先順位を決める、図面との照合結果を最終確認する、発表の講評 |
| 技術サポート | ICT・CAD担当の社員 | Blender の操作指導、PC の準備、レンダリング |
| 道路班 | 生徒A | **市道羽場線**と**市道油田線**：車道・歩道・縁石・側溝・擁壁・柵・進入路 |
| 鉄道・踏切班 | 生徒B | **堂の前踏切**：線路、踏切舗装版、遮断機・警報機、歩道、L型擁壁、照明 |
| 演出・発表 | A・B 共同 | カメラ位置、測点注記、比較スライド、発表 |

- 3か所は性格がちがいます（羽場線は農道の改良、油田線は歩道の設置、踏切は鉄道との交差）。そのため、道路系2か所と踏切1か所に分けて担当します。
- Blender のコレクションも同じ単位で分けています（`道路` `歩道` `排水` `施設` `鉄道` `地形` `周辺` `測点`）。作業がぶつからないように、担当のコレクションだけを触ります。

## 3日間の進め方

| 日 | 内容 |
|---|---|
| 1日目 午後 | 3か所の位置図・平面図で概要を知る。Blender の基本操作 |
| 2日目 | 担当箇所の図面とモデルを見比べ、下の「要確認」を一つずつ確かめて直す |
| 3日目 午前 | レンダリング、測点注記入りの画像づくり、発表準備 |

## 使い方

```
blender -b -P habasen_kansei.py -- --site=haba   --render          # 市道羽場線
blender -b -P habasen_kansei.py -- --site=yuden  --render          # 市道油田線
blender -b -P habasen_kansei.py -- --site=doumae --render --save   # 堂の前踏切（.blend も保存）
python annotate_sites.py                                            # 測点注記を描き込む
```

- 画像は `renders/<箇所>/` に、測点注記入りの画像は `renders/<箇所>/annotated/` に出ます。
- Blender の画面から実行するときは、スクリプト冒頭の `SITE = "..."` を変えてください。

- **区間**：今年度は NO.0〜NO.4+13.00（L=93m）。図面全体は約814mの計画。
- **線形**：R=650 の大きな曲線（BC1 NO.-1-18.4、EC1 NO.1+14.046）から直線へ。縦断勾配は +0.30%〜+0.93%。
- **横断**：全幅6.5m（車道2.75m×2）、両側に土留め付き皿型側溝（左400型、右500型）。横断勾配は拝み2%。
- **施設**：
  - 外側線（白実線15cm）
  - グレーチング（約20mごと）、集水桝3か所、マンホール3か所
  - 進入路5か所（R1 は幅11.5m）
  - スノーポール11本
  - 照明灯1基（NO.0+13.24 右、H=8m）

### 市道油田線（図面 08-02）
- **区間**：NO.21+15.45〜NO.25+2.50（L=67m）。直線で、縦断勾配は +4.1%〜+5.8% の上り坂。
- **横断**：車道7.0m（既設）。北側に歩道2.2mを新設（歩車道境界ブロックB種）し、車道は縁石寄り1.0mを打換え。
- **歩道の外側**：
  - 起点側：1:1.5 の盛土法面で田へ下ろす。
  - 終点側約22m：可変勾配側溝B500とL型擁壁（H=2.5m）で擁壁状にし、転落防止柵 H=1.1m を付ける。
- **施設**：
  - 進入路2か所（W=4.0m）
  - 縁石の切下げ・車両乗入れ部
  - 視線誘導標4本、ポストコーン5本
  - 南側に既設U型側溝
- **周辺**：北は田（EL.176.80）、南は切土斜面と台地、脇道2本、電柱列。終点の先の北側に民家。

### 堂の前踏切（図面 08-03）
- **踏切**：JR山田線（単線・非電化）と交差角67°で交差。踏切中心は NO.2+5.726。
- **線形**：直線 → R20（左）→ R25（右）の S字 → 直線（踏切）→ R110（右）。
- **縦断**：踏切が頂部で、前後は ±7.5% の坂。
- **横断**：
  - 一般部：歩道2.0m＋車道5.0m（0.5+4.0+0.5）
  - 踏切部：歩道2.0＋施設帯1.2＋車道5.0＝8.2m。総研型踏切舗装版を敷く。
- **施設**：

  - 停止線2本（No.2+0.5、No.2+11.0）

- **周辺**：北側は住宅、南側は集合住宅が並ぶ市街地。

## 要確認（図面どうしで食い違う所・読めなかった所）

| 箇所 | 内容 | モデルでの扱い |
|---|---|---|
| 羽場線 | センターラインを引くか（数量190mは外側線2本分と同じ） | 外側線のみ |
| 羽場線 | 起点の交差点の形（T字か十字か）と鹿妻幹線水路の正確な位置 | 十字・水路は交差道路沿い（仮） |
| 羽場線 | スノーポールの位置 | 等間隔（仮） |
| 油田線 | 標準断面2の適用範囲（NO.22+17.15 は NO.23+17.15 の誤記か） | NO.23+17 から擁壁区間 |
| 油田線 | 縁石天端の高さ、脇道の幅 | 縁石15cm、脇道は形だけ |
| 踏切 | L型擁壁・転落防止柵が北側か南側か（平面図と横断図で食い違う） | 北側（横断図に合わせた） |
| 踏切 | 線路の反対側の遮断機の配置、「止まれ」標示の有無 | 両側に同じ3基、標示なし |
| 踏切 | 線路は R=300 の曲線・8.3‰ の勾配 | 直線・水平（簡略化） |

- 地形、建物、樹木は図面の記号をもとにした「それらしい形」で、測量データではありません。
- 外部に見せる前に、発注者（盛岡市）の確認を取ってください。
