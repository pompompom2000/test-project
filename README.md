# みんなであそぼ

ゲームの中の幼稚園を自分のキャラで歩き、あそびばで遊びながら「つくる力」と「おともだちと なかよくする力」を育てるタブレット向けアプリ（PWA）です。
「ゆうぎしつ」では、2〜4 チームに分かれて遊ぶチーム対戦ゲームもできます。
文字が読めなくても遊べるよう、問題や指示は音声で読み上げ、操作は大きなボタンをタップするだけです。

## ようちえんの あそびば

点数や勝ち負けはありません。おともだちに やさしい ことばを えらぶと、ハートが増えて「なかよし ノート」に たまります。よくない ことばを えらんでも しからず、相手の気もちに 気づける ヒントが出て、もう一度 えらべます。

| あそびば | つくる | なかよく する |
| --- | --- | --- |
| 🎨 おえかき | クレヨン・スタンプで自由に描き、ギャラリーに飾る | クレヨンを「かして」→「どうぞ」、絵を見せあって ほめあう |
| 🧱 つみき | 形と色を選んで高く積む。続きから遊べる | 一緒に作る、「さんかく ほしいな」→「どうぞ／じゅんばんこ」、ぶつかって「ごめんね」「いいよ」 |
| 🍳 おままごと | 食材を組み合わせて自由に料理する | 「どうぞ」「いただきます」、コックさんを交代、一緒に おかたづけ、こぼした友だちを助ける |
| 🏖️ すなば | 掘る・盛る・型ぬき・水を流す | スコップを貸す、一緒に大きな お城を作る、「いれて」→「いいよ」 |
| 🛝 すべりだい | すべって遊ぶ | 順番を守る、こわがる年少さんに「さきに どうぞ」、ハイタッチ |
| 🎪 ゆうぎしつ | チーム対戦ゲーム（下の表） | チームで協力 |

地図の上の おともだちを タップすると、「おはよう」「だいじょうぶ？」「いれて」「ごめんね」「ありがとう」などの場面が出ます。
作った作品や ハートは、そのタブレットのブラウザに保存されます。

## チーム対戦ゲーム（ゆうぎしつ）

| ゲーム | 遊び方 |
| --- | --- |
| 🎨 いろ あて クイズ | チームの順番に、読み上げられた色・くだもの・鳴き声の動物をカードから選びます。まちがえても減点はなく、もう一度選べます |
| 🧺 たまいれ タップ | 画面をチームごとのエリアに分け、30 秒間、自分のエリアに出てくるボールを全員で同時にタッチします |
| 🃏 えあわせ カード | 神経衰弱です。同じ絵の 2 枚がそろったら 1 点で、そのチームがもう一回めくれます |

チームは 🐰うさぎ・🐻くま・🐸かえる・🐥ひよこ。最後の結果画面では、勝ったチームに関係なく「みんな よく がんばったね！」と全員をほめます。

## 使い方

ビルドは不要です。静的ファイルをそのまま配信してください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ をタブレットのブラウザで開く
```

GitHub Pages などに置いて、iPad の Safari で開き「ホーム画面に追加」すると、アプリのように全画面で起動します。一度開けばオフラインでも遊べます。
右上の 🔔／🗣️ ボタンで、効果音と読み上げをそれぞれオン・オフできます。

## ゲームを追加するには

`js/games/<id>.js` で `Core.registerGame({ id, title, emoji, color, start(ctx) })` を呼び、`index.html` と `sw.js` にファイルを追加します。
`ctx` の中身は `js/app.js` の `startGame` を見てください。
