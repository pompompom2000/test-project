# 道悪ファクター予想ツール

雨の日の競馬（稍重・重・不良）に特化した予想支援ツールです。
馬場状態・血統（種牡馬）・馬体重・過去実績に、コース傾向と当日の開催バイアスを重ねて各馬を採点します。

ビルド不要の静的サイトなので、`index.html` をブラウザで開けばそのまま動きます。
GitHub Pages に置く場合もそのまま公開できます。

```
open index.html          # macOS
xdg-open index.html      # Linux
```

## できること

- **良馬場評価との比較**：良馬場での評価順と、その馬場での評価順を並べて表示します。
  道悪は「良馬場の成績がアテにならない」条件なので、どの馬が評価を上げ／下げたのかが一目で分かります。
- **波乱度**：馬場状態、評価の入れ替わり具合、当日3着内馬の平均人気から算出します。
- **買い方のスタンス**：重・不良では「金額を抑える」「見（ケン）」も選択肢として提示します。
- **妙味の判定**：単勝オッズを入れると、市場の評価順とツールの評価順の差を表示します。

## 採点ファクター

| ファクター | 内容 |
| --- | --- |
| 基礎能力 | 良馬場での複勝率（30%を基準） |
| 血統 | 種牡馬ごとの「重・不良で狙える／狙い難い」、馬場状態別の「要注意／いまいち」、牡牝別の傾向 |
| 馬体重 | ダートの重・不良では500kg以上が有利。芝は440kg以上なら差はほぼ出ない |
| 道悪実績 | 良馬場と道悪の複勝率の差。道悪の出走数が少ないうちは補正を弱める |
| コース傾向 | そのコースの枠順・脚質の傾向（馬場状態で切り替わる） |
| パドック | 当日の気配。未入力の馬は加点も減点もしない |
| 調教 | 追い切り評価のランク（S〜D、Bが基準）と短評のキーワード |
| 外厩 | 調整先の施設別成績。休み明けの馬はこのファクターの比重を上げる |
| 厩舎コメント | 陣営が道悪を歓迎しているか／良馬場を望んでいるか、仕上がりの評価 |
| 当日の傾向 | 同日の前のレースで3着内に来た枠番・脚質・騎手・調教師・血統、および人気 |

血統・馬体重以外のファクターは馬場状態に応じた「道悪度」（良0／稍重0.35／重0.85／不良1.0）で強さが変わります。

## 的中確率を計算する

```
node tools/probability.js data/races/2026-09-20-nakayama-11r.json
node tools/probability.js <race.json> 3連複:12,2,3,6,5 ワイド:12,2,3
node tools/probability.js <race.json> --check=8,1,4     # 実際の着順で答え合わせ
```

評価スコアをソフトマックスで勝率に変換し、Harville モデル（復元なしの逐次抽選）で
2着・3着の確率を求めます。ソフトマックスの温度は、市場（単勝オッズ）の確率分布と
エントロピーが揃うように自動で決めるので、温度の決め打ちをしません。

**モデル単独の確率はそのまま信じないでください。** 市場と評価順が食い違う馬では
期待値が数倍という非現実的な値になります。既定では市場の確率と対数線形で合成し
（モデルの重み 0.15、`--blend=` で変更可）、市場からの「ずらし幅」としてモデルを
使う形にしています。

## 検証結果（2025〜2026年 芝・重／不良 59レース）

`node tools/validate.js data/validation/*.json` の結果:

| | 単勝の対数損失 | 複勝の対数損失 | 本命の複勝率 |
| --- | --- | --- | --- |
| 市場のみ（w=0） | 2.1265 | 0.4513 | 47.5% |
| w=0.20 | 2.1405 | **0.4451** | 52.5% |
| モデルのみ（w=1） | 2.7184 | 0.5463 | 42.4% |

**モデル単独は市場より明確に劣ります**（対数損失で0.59悪い）。市場と混ぜた場合、
複勝では w=0.20 付近でわずかに改善しますが、単勝では市場のみとの差が
0.0012 ± 0.0073（t=0.17）で誤差の範囲です。

現時点の結論は「**このモデルは市場に情報を足せているとは言えない**」です。
既定の重みを 0.15 にしているのは、モデルを完全に捨てるほどの反証もないためです。

## 係数を学習した場合（tools/fit.js）

手で決めた係数ではなく、同じ59レースから条件付きロジット（Plackett-Luce）で
係数を学習した場合の結果です。正則化の強さと性能はいずれも交差検証で測っています。

```
node tools/fit.js data/validation/*.json            # 特徴量のみ
node tools/fit.js --with-market data/validation/*.json
node tools/fit.js --offset data/validation/*.json   # 市場を係数1固定のオフセットに
```

| 設定 | 交差検証の単勝対数損失 |
| --- | --- |
| 市場のみ | 2.1265 |
| 特徴量のみ（学習後） | 2.5318 |
| 市場＋特徴量（市場も正則化） | 2.2339 |
| **市場をオフセット＋特徴量** | **2.1100** |

特徴量だけで組むと、係数を最適化しても市場に0.41及びません。市場をオフセットに
固定して上乗せする形にすると 0.0165 改善しますが、

```
市場 − モデル の損失差: 0.0165 ± 0.0297（標準誤差, n=59）→ t=0.56
```

誤差の範囲です。しかも最適な λ を同じ交差検証で選んでいるので、この差は
実際より楽観的に出ています。**59レースでは市場を上回っていると言えません。**

`--check=` を付けると、実際の着順にモデルが与えていた確率を、モデル単独・合成・
市場の3通りで並べて表示します。

## 秋G1での検証（2015〜2025年・芝114レース）

秋（9〜12月）のG1を11年ぶん集めて検証した結果です。秋G1は88%が良馬場で、
道悪向けの特徴量では補正がすべてゼロになるため、クラス経験・距離適性・
コース適性・ローテーションなどを加えた24個の特徴量で学習しています。

```
node tools/fit.js --g1 data/validation-g1/*.json
node tools/fit.js --g1 --offset data/validation-g1/*.json
```

| 設定 | 交差検証の単勝対数損失 |
| --- | --- |
| **市場のみ** | **1.7331** |
| 特徴量のみ（学習後） | 2.0438 |
| 市場をオフセット＋特徴量 | 1.7343 |

特徴量だけで組むと市場に0.31及びません（t=−5.97 で統計的にはっきり悪い）。
市場をオフセットに固定して上乗せする形でも 1.7343 とわずかに悪く、
−0.0012 ± 0.0045（t=−0.26）で改善はありません。最適な正則化が λ=300 という
非常に強い値になり、係数がほぼゼロへ縮む＝「市場をそのまま使え」という
結論になっています。

秋G1での市場の損失1.7331は、道悪59レースでの2.1265より小さく、**秋G1は
市場の予測精度が高い**（人気どおりに決まりやすい）ことを示しています。

### 学習された係数から分かること（特徴量のみの場合）

市場を上回れないとはいえ、どの材料が着順と結びつくかは読み取れます。

| 特徴量 | 係数 |
| --- | --- |
| 前走着順 | +0.358 |
| 年齢 | −0.343（若い馬が有利） |
| G1の経験 | +0.342 |
| 重賞の3着内率 | +0.303 |
| 芝の勝率 | +0.239 |
| 前走人気 | +0.237 |

秋G1では**直前の走りと、重賞・G1でのクラス経験**が効きます。年齢の係数が負なのは、
菊花賞・秋華賞の3歳馬や阪神JF・朝日杯FSの2歳馬が含まれるためです。

## コマンドラインから使う

```
node tools/predict.js data/races/2026-09-20-nakayama-11r.json
```

入力 JSON の形は `data/races/2026-09-20-nakayama-11r.json` を参照してください。
`surface`（turf / dirt）、`state`（firm / good / yielding / soft）、`courseKey`、
`trend`（当日の傾向）、`horses` を持ちます。

当日の傾向は、競馬ラボ「本日の傾向」などの成績一覧を手で入力して使います（データの自動取得はしていません）。
厩舎コメントも同様に、各馬の陣営コメントを読んで「道悪歓迎／良馬場希望」「仕上がり良好／不安」に分類して入力します。
調教評価は netkeiba の追い切り評価（ランクと短評）を入力します。詳細な追い切りタイムは有料会員限定のため扱っていません。

## 注意

種牡馬データは全距離・全競馬場をまとめた集計で、当日の傾向は数レースの小サンプルです。
厩舎コメントの分類は読み手の解釈が入ります。
出典記事にもあるとおり、すべてを鵜呑みにせず参考程度に。最終的な判断は自己責任でお願いします。
馬券は20歳以上になってから。
