# test-project

## 概要

`test-project` は、Claude Code（リモート実行環境）の動作確認およびワークフロー検証のために作成されたテスト用リポジトリです。

現時点ではアプリケーションコードや依存関係は含まれておらず、リポジトリはほぼ空の初期状態です。ブランチ運用、コミット、プッシュ、プルリクエストといった一連の開発フローを、実プロダクトに影響を与えずに試すための場所として利用します。

## 使い方

リポジトリを取得します。

```bash
git clone https://github.com/pompompom2000/test-project.git
cd test-project
```

実行可能なコードはまだ無いため、ビルドや起動のコマンドはありません。新しい検証を始める場合は、目的に応じてこのディレクトリ配下にファイルを追加してください。

## ブランチ運用

- `main`: 既定のブランチ。
- 作業用ブランチ: 変更は `main` から切ったブランチ上で行い、プルリクエスト経由で取り込みます。

```bash
git checkout -b <ブランチ名>
# 変更を加える
git add .
git commit -m "変更内容の説明"
git push -u origin <ブランチ名>
```
