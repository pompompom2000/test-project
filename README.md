# 傭車の考え方と利用運送の登録判断

有限会社石名坂商事（一般貨物自動車運送事業許可あり・大型ダンプ5台）と、親会社の
株式会社石名坂（運送業の許可なし・砕石の売主）を前提に、**ダンプの傭車をどこまで
出せるか／どの手続が要るか**を調べてまとめたものです。岩手県内の砕石・建設現場が
前提になっています。

全文は `docs/legal-research/` にあります。

## 結論だけ先に

| 論点 | 結論 |
|---|---|
| 緑ナンバーへの傭車 | **出せる。** 必要なのは一般貨物の**事業計画変更認可**（貨運法9条1項）だけ。利用運送法の登録は不要（同法19条の適用除外）。ただし事業計画に「貨物自動車利用運送＝行う」の記載があることが前提で、標準処理期間は1〜4か月 |
| 水屋（利用運送専業者）への傭車 | **第一種貨物利用運送事業の登録が必要**（貨運法2条7項の括弧書き／利用運送法3条1項） |
| 白ナンバー・一人親方への傭車 | **委託そのものが禁止**（貨運法65条の2）。100万円以下の罰金（75条14号）、法人にも両罰（80条） |
| 有限会社石名坂商事の第一種登録 | **不要。** 変更認可で足りる |
| 株式会社石名坂（親会社）の第一種登録 | **不要、かつ取るべきでない。** 自社の砕石を届けるための委託は利用運送事業に当たらず、登録すると真荷主でなくなって現在の書面・管理簿の前提が崩れる |
| 産廃を他社ダンプに運ばせる場合 | **規制が二階建て**。1階＝貨運法（変更認可）、2階＝廃掃法14条16項の再委託（令6条の12の4要件を全部満たすこと。核は**排出事業者の事前の書面承諾**） |
| 直近で変わること（2026年10月1日） | **社会保険の賃金要件（月8.8万円未満）が本則から削除**。適用除外は週20時間未満と学生の2つに。当社は特定適用事業所（常時50人超）でないため**判定は4分の3基準のみのまま**（PDF 36章・64章） |
| 2028年6月10日に変わること | 一般貨物の許可が**5年ごとの更新制**に。**適正原価**が導入され、**傭車に出す単価も適正原価を下回れなくなる**（法9条の3第2項）。**標準的な運賃は廃止**（PDF 64章） |
| **白ダンプで運んでよいか** | **4つの関門を全部通ったときだけ。**①貨運法（誰の荷物を誰が有償で運ぶか）②ダンプ規制法（その荷は「土砂等」か＝ゼッケン）③労働・社会保険（誰が雇っているか）④廃掃法（産廃か）。**1つでも落ちれば、残り3つが完璧でも違法**（PDF 65〜68章） |
| がれき類と汚泥の違い | **ダンプ規制法の「土砂等」と廃掃法の「産廃」は別の軸。**がれき類は**産廃かつ土砂等**（ゼッケンも許可も要る）。汚泥は**産廃だが土砂等ではない**（ゼッケンは不要）。砕石・砂利は**産廃ではないが土砂等**（PDF 66章） |
| 白ナンバーのダンプを適法に動かす形 | **委託ではなく「雇用」だけ。**令和8年2月10日・5月1日・8月20日の事務連絡が、**誰が雇うのか**（5つの場面）と**交わす書面**（労働条件通知書＋**車両使用通知書**）を示した。**「委託できない」という結論は変わらない** |
| 持込み白ダンプで1日に複数事業者 | **不可能ではないが、成り立つ形は1つだけ。**①車検証上の使用者が運転者本人のまま、②運転者本人が自分の事業で**ダンプの表示番号（ゼッケン）**を取得している場合に限る。表示番号は「使用者が経営する事業」に対応し**車検証に記入**されるので、雇主ごとに付け替えられない。加えて**労働時間は事業主が違っても通算**される（労基法38条1項）|
