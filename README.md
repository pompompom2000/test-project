# みんなであそぼ

幼稚園で、子どもたちが 2〜4 チームに分かれて遊べるタブレット向けゲームアプリ（PWA）です。
文字が読めなくても遊べるよう、問題や指示は音声で読み上げ、操作は大きなボタンをタップするだけです。

## ゲーム

| ゲーム | 遊び方 |
| --- | --- |
| 🎨 いろ あて クイズ | チームの順番に、読み上げられた色・くだもの・鳴き声の動物をカードから選びます。まちがえても減点はなく、もう一度選べます |
| 🧺 たまいれ タップ | 画面をチームごとのエリアに分け、30 秒間、自分のエリアに出てくるボールを全員で同時にタッチします |
| 🃏 えあわせ カード | 神経衰弱です。同じ絵の 2 枚がそろったら 1 点で、そのチームがもう一回めくれます |

チームは 🐰うさぎ・🐻くま・🐸かえる・🐥ひよこ。最後の結果画面では、勝ったチームに関係なく「みんな よく がんばったね！」と全員をほめます。

## 使い方

ビルドは不要です。静的ファイルをそのまま配信してください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ をタブレットのブラウザで開く
```

GitHub Pages などに置いて、iPad の Safari で開き「ホーム画面に追加」すると、アプリのように全画面で起動します。一度開けばオフラインでも遊べます。
右上の 🔔／🗣️ ボタンで、効果音と読み上げをそれぞれオン・オフできます。

## ゲームを追加するには

`js/games/<id>.js` で `Core.registerGame({ id, title, emoji, color, start(ctx) })` を呼び、`index.html` と `sw.js` にファイルを追加します。
`ctx` の中身は `js/app.js` の `startGame` を見てください。
