# Claude に記事を直してもらうとき

2026年9月14日に作った覚え書き。次に頼むときは、これを見せれば話が早い。

---

## 1. 準備（30秒）

WordPress管理画面 → **ユーザー** → **ai-agent** → ページの一番下

**「アプリケーションパスワード」** の欄で、名前に `claude` と入れて
**「新しいアプリケーションパスワードを追加」**。

`abcd EFGH 1234 ijkl MNOP 5678` のような **空白区切りの24文字** が
1回だけ表示される。これを Claude に渡す。

> **ログインパスワードは渡さない。**
> 記号（`&` `^` `*` など）が入っていて空白が無いものは、ログイン用。別物。

## 2. 終わったら（10秒）

同じ画面で、そのパスワードを **「取り消す」**。

- **ユーザー（ai-agent）は消さなくてよい。** 残しておく。
- パスワードは何本でも作れて、1本ずつ取り消せる。**毎回使い捨てにする。**
- 最後に使われた日が表示されるので、身に覚えのない日付が出たらすぐ分かる。

## Claude にできること・できないこと

| | |
|---|---|
| 記事・固定ページを読む | できる（生のデータごと） |
| 記事・固定ページを書き換える | できる |
| 画像をダウンロードして中身を見る | できる |
| 公開ページの確認 | できる |
| 管理画面の中を見る | **できない** |
| Easy Accordion（FAQの中身） | **できない**（RESTから触れない） |
| YouTubeの動画 | **できない**（接続が遮断されている） |
| e-Gov法令検索 | **できない**（同上。条文は画面をコピーして渡す） |
| Wikipedia | **できない**（同上） |

**ai-agent は編集者権限。** プラグインの追加も設定変更も利用者の追加もできない。
記事の編集だけ。それ以外の権限は渡していない。

---

## 進め方の約束

1. **書き換える前に、必ず「この文をこう変えます」を見せてもらう。** 黙って変えない。
2. 置き換え先が1か所に定まることを機械的に確認してから実行する。
3. 実行後は公開ページで照合する。
4. 書き換え前の本文を `wordpress/edits/日付/` に保存する。
   WordPress側にも投稿ごとの履歴が残るので、**どの1件でも元に戻せる。**
