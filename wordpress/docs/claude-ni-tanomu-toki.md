# Claude に記事を直してもらうとき

2026年9月14日に作った覚え書き。次に頼むときは、これを見せれば話が早い。

---

## 1. 準備（30秒）

WordPress管理画面 → **ユーザー** → **ai-agent** → ページの一番下

**「アプリケーションパスワード」** の欄で、名前に `claude` と入れて
**「新しいアプリケーションパスワードを追加」**。

`abcd EFGH 1234 ijkl MNOP 5678` のような **空白区切りの24文字** が
1回だけ表示される。これを Claude に渡す。

> **ログインパスワードは渡さない。**
> 記号（`&` `^` `*` など）が入っていて空白が無いものは、ログイン用。別物。

## 2. 終わったら（10秒）

同じ画面で、そのパスワードを **「取り消す」**。

- **ユーザー（ai-agent）は消さなくてよい。** 残しておく。
- パスワードは何本でも作れて、1本ずつ取り消せる。**毎回使い捨てにする。**
- 最後に使われた日が表示されるので、身に覚えのない日付が出たらすぐ分かる。

## Claude にできること・できないこと

| | |
|---|---|
| 記事・固定ページを読む | できる（生のデータごと） |
| 記事・固定ページを書き換える | できる |
| 画像をダウンロードして中身を見る | できる |
| 公開ページの確認 | できる |
| 管理画面の中を見る | **できない** |
| Easy Accordion（FAQの中身） | **できない**（RESTから触れない） |
| YouTubeの動画 | **できない**（接続が遮断されている） |
| e-Gov法令検索 | **できない**（同上。条文は画面をコピーして渡す） |
| Wikipedia | **できない**（同上） |

**ai-agent は編集者権限。** プラグインの追加も設定変更も利用者の追加もできない。
記事の編集だけ。それ以外の権限は渡していない。

## 進め方の約束

1. **書き換える前に、必ず「この文をこう変えます」を見せてもらう。** 黙って変えない。
2. 置き換え先が1か所に定まることを機械的に確認してから実行する。
3. 実行後は公開ページで照合する。
4. 書き換え前の本文を `wordpress/edits/日付/` に保存する。
   WordPress側にも投稿ごとの履歴が残るので、**どの1件でも元に戻せる。**

### 書面化義務の条文番号（2026-09-17に範囲を確認し直した）

「トラック協会か国交省に確認」と書いていたが、**外部への照会は要らない**。
6つの法定事項は法律と省令に書いてあるので、e-Govで条文を開けば済む。

条文番号が無いのは1本ではなく**3本すべて**だった。

| 記事 | 条文番号 | 外部の出典リンク |
|---|---|---|
| `industrial-waste-contract` | なし | なし |
| `kaisei-kamotsu` | なし | `mlit.go.jp/jidosha/`（トップ階層だけ） |
| `post-1470`（国交省の解釈を確認、という題） | なし | **1本もなし** |

記事の中身そのものは妥当。`industrial-waste-contract` は産廃法の解説ではなく、
改正貨物自動車運送事業法の6つの法定事項を自社の契約書に当てはめた点検記事で、
自社の不備3か所（2・3・5）と、運送申込書で補完している運用まで書いてある。
**弱いのは条文番号だけ。**

必要なもの（e-Gov `https://laws.e-gov.go.jp/` で「貨物自動車運送事業法」→ `書面` で検索）

1. 書面の交付を義務づけている**法律**の条文
2. 6つの記載事項を列挙している**施行規則**の条文（中身は省令側にあることが多い）

入れ方：「改正貨物自動車運送事業法には次の項目を記載しなければなりません」の直後に
根拠を1行足し、出典欄にe-Govの該当条文を追加する。**3本とも同じ形に揃える。**

国交省への問い合わせが要るのは、記事が自分で挙げている
「書面の交付年月日」と「契約年月日」の違いという論点だけ。
そこは記事がすでに「詳しくは国交省に問い合わせてください」と書いてあり、このままでよい。

**このセッションからは e-Gov・国交省・トラック協会がすべて遮断されている。**
条文は人の手で取ってくる必要がある。
