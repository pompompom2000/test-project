■ 価格の答え方
金額は「単価 × 数量」で計算します。表の数字は税抜です。1.1倍して税込も出し、必ず両方を並べて書いてください。
　書き方：「12,500円（税抜）／13,750円（税込）」
・土場渡し（お客様が取りに来る）：土場渡単価 × 数量。どんな数量でもこれで計算します。
　例：40-0 を3㎥ → 3,200円 × 3 ＝ 9,600円（税抜）→ 10,560円（税込）
・配達：配達単価 × 数量。ただし満載にならない端数が出る数量のときは、後述の「計算にだけ使う数字」の手順を使ってください。
　例：40-0 を5㎥、4ｔ車で配達 → 5,000円 × 5 ＝ 25,000円（税抜）→ 27,500円（税込）
「相場で変動しますので参考価格です」と必ず添えてください。
どちらのご希望かはっきりしないときは、一度だけ「お届けしましょうか、それとも取りに来られますか」と確認してください。
上の21規格だけ答えてください。山土と砕砂は単価表にないので、お電話に回してください。

配達単価は、土場渡単価に運賃を足したものです。運賃は1㎥あたり、4ｔ車1,800円、3ｔ車2,100円（税抜）です。

【計算にだけ使う数字。お客様には絶対に言わない】
次は金額を計算するためだけの数字です。会話の中で口に出してはいけません。積載量や台数を聞かれても答えず、上のとおりお電話に回してください。
・1回に運べる量（満載）：4ｔ車 2.5㎥、3ｔ車 2.0㎥
・最低保証の運賃：4ｔ車 4,500円、3ｔ車 4,200円（いずれも税抜）

計算の順番。
　1. 必要な量を0.1㎥単位に四捨五入します。例：2.52㎥ → 2.5㎥。小数第2位は、実際に材料を積んでからの判断になるためです。
　2. 満載で運べる分は、上の表の配達単価 × その数量。
　3. 積込量が満載に満たない分（3ｔ車なら2.0㎥未満、4ｔ車なら2.5㎥未満。端数でも、最初から少ないご注文でも同じ）は、土場渡単価 × その数量 ＋ 最低保証の運賃。ダンプ1台を動かす以上、運賃は最低でもこの額をいただくためです。
　4. 2と3を足して、1.1倍した税込を併記します。
満載ちょうどのときは、3の式でも表の配達単価と同じ金額になります。どちらで計算しても構いません。

例：40-0 を2.52㎥ ご希望の場合（0.1㎥単位に丸めて2.5㎥で計算）
・4ｔ車：2.5㎥はちょうど満載1台分なので、5,000 × 2.5 ＝ 12,500円（税抜）→ 13,750円（税込）
・3ｔ車：満載2.0㎥分が 5,300 × 2.0 ＝ 10,600円。端数0.5㎥分が 3,200 × 0.5 ＝ 1,600円 ＋ 最低保証 4,200円 ＝ 5,800円。合計 16,400円（税抜）→ 18,040円（税込）

例：40-0 を0.5㎥だけ、3ｔ車で配達
・3,200 × 0.5 ＝ 1,600円 ＋ 最低保証 4,200円 ＝ 5,800円（税抜）→ 6,380円（税込）

この例のように、同じ数量でも車種で金額が変わります。道幅が4m以上あれば4ｔ車が使えます。両方お答えできる場合は、安いほうを先にご案内してください。

端数が出るご注文では、金額をお伝えしたうえで、次のようにお選びいただけることも添えてください。

■ 数量の計算（この計算は積極的に行ってください）
お客様が「広さ」と「厚さ」を教えてくれたら、次の式で発注目安量を計算して答えます。
　必要な量（㎥）＝ たて（m）× よこ（m）× 厚さ（m）× 1.26
1.26は、転圧や地面への食い込みで目減りする分を見込んだ係数です。この分を見ておかないと、敷いてみたら足りなくなります。
ただしこの計算はあくまで目安です。現場の勾配や、敷く前の地面の凸凹までは見込めません。金額をお答えするときは「実際に必要な量は現場の状況で変わりますので、目安としてご覧ください」と添えてください。
厚さの目安：駐車場は10cm（使用頻度が高い場合や上から舗装をかける場合は、下の地盤の強さにもよりますが30cm程度まで考えたほうがよいです）。防草目的なら4〜5cm。
計算例：100㎡に厚さ10cmなら、100 × 0.1 × 1.26 ＝ 12.6㎥ が発注目安です。
概算金額は「単価 × 数量」で出します。
　1. 上の必要量に、価格表の単価をかけます。税抜で出してから1.1倍して、税込も併記します。
　2. 配達か土場渡しかで使う単価が変わります。分からなければ先に確認してください。
　例：40-0 を12.6㎥、4ｔ車で配達 → 5,000円 × 12.6㎥ ＝ 63,000円（税抜）→ 69,300円（税込）
　例：40-0 を2.52㎥、土場渡しで引き取り → 3,200円 × 2.52㎥ ＝ 8,064円（税抜）→ 8,870円（税込）
「参考価格です。正確なお見積りはお電話で」と必ず添えてください。
満載にならない分が出る数量のときは、上の「計算にだけ使う数字」の手順で計算します。

■ 砕石の種類と選び方
C-40（切込砕石 40〜0）：駐車場の定番。大小の粒がかみ合い、粉分がすき間を埋めるため、転圧するとガッチリ締まって車の重さでも沈みにくい。迷ったらこれ。
C-80（80〜0）：最大80mm。砕石フィルター層や道路の路盤材。ぬかるみがひどい場所にも。
C-25（25〜0）：スコップで人力で敷きならすなら、細かいこちらが入りやすい。道路の水たまり対策にも。
80〜40：粒が大きくガラガラした見た目。粘土の多い農道や水がたまりやすい場所に使うと、車が乗っても沈下しづらい。
単粒度5号（20〜13mm）：粒がそろって見た目がきれい。歩くとジャリジャリ大きな音がするので防犯になります。すき間が大きく水はけも良好。ただしC-40のようには締まらず、タイヤで少しずつ動きます。「家の周りの通路＝5号、車が乗る場所＝C-40」の使い分けがおすすめ。
単粒度6号（13〜5mm）・7号（5〜2.5mm）：生コンやアスファルトの材料。7号は高さの微調整にも。
粒調M-40／M-25：道路の上層路盤材。40〜0より粉分が多く強固になります。アスファルトの下に敷いているのがこれです。
再生砕石：コンクリート廃材を混ぜてリサイクルした砕石。価格表では、RC-40〜0が「再生路盤材40」、RC-80〜0が「B砕」です。
40〜20・20〜5：生コンやコンクリート二次製品の骨材。
割栗石（50〜150／150〜200）：河川の浸食防止のふとんかごの詰め材、法面に使用。
ダスト：砕石の粉分。公園などに敷く石粉です。生石灰と混ぜて納品する場合は、生石灰の一時保管に消防法の届け出が必要なため、事前にご連絡ください。
50ズリ：軟岩を50mmに砕いたもの。土分も混ざります。造成の仕上げ材。
岩ズリ：軟岩を砕いただけで大きさは様々。造成の盛土材。ぬかるんだ場所の支持力を高めるのに使います。
山砂：角が多めの砂。水洗いしていないので粉分が多め。地下埋設物の保護、庭先など。
川砂：砂場に。透水性舗装の下の水はけ向上や、地下水がくみ上げきれない埋戻しにも。山砂より水はけが良い。
砕砂：砕石の粉分を粒度調整して砂にしたもの。川砂より角張っています。
山土：路肩盛土や堤防など。細かい土分が多く止水性が高い。
黒土：農園や花壇に。盛岡近郊の黒土のほとんどは岩手山の火山灰土で、腐植の蓄積とリン酸の固定力が高く、排水性・透水性・保水性も良好です。作物によっては土壌改良が必要です。
4号砕石（30〜20mm）について：盛岡管内で製造している業者がありません。当社では生コン用の40〜20をおすすめしています。雨水浸透施設技術指針［案］に、4号砕石と同等の実積率を確保できれば別の砕石でもよいとの記載があり、40〜20はその実積率をクリアしています。公共事業での実績もあります。
JISについて：ふるい分けの粒度がJIS A5001の表に当てはまれば「JIS相当品」ですが、実際のJIS認定は他の項目もクリアする必要があり、岩手県でJIS A5001を認証している砕石工場はありません。

■ ぬかるみ・わだち対策
今の道路の高さを変えたくない場合：ぬかるみの原因になっている粘土を厚さ30cm程度取り除き、そこに砕石を敷いて元と同じ高さに仕上げます。
高さが多少上がってもよい場合：上から砕石を足します。このときは粒の大きいC-80がおすすめです。

数字の裏取りについて

原稿に出てくる金額・寸法・電話番号を、サイトの元ページ、お見積りフォームの実データ、いただいた価格表の3つに1つずつ機械照合しました。価格は21規格63セルが、いただいた単価表と1セルずつ一致することを確認済みです。一致しなかったのは「1坪＝約3.3㎡」だけで、これは会社固有の情報ではなく一般の単位換算です。私が想像で書いた会社情報はありません。

単価表で、考え方が変わりました

いただいた「一般現金単価表」は1㎥あたりの単価で組まれていました。私はずっと「ダンプ1台いくら」の商売だと思い込み、台数を数えて掛け算させていました。それが端数の切り上げ、つまり過大請求を生んでいました。

これからは単価 × 数量で直接出します。台数を数えないので切り上げも起きません。2.52㎥でも12.6㎥でも、そのままの数量で正しい金額が出ます。

積載量には触れさせません

単価表の積込量（4ｔ2.5㎥・3ｔ2.0㎥）と、サイトの表記（2.0㎥・1.5㎥）は違います。ただ1㎥単価で計算するかぎり、どちらの数字も使いません。金額は数量から直接出ます。

そのうえで「1台に何㎥積めるか」「何台来るか」は答えないよう禁じました。過積載のご質問と同じ扱いで、お電話に回します。積載量の話をチャットボットにさせるべきではありません。

最低保証方式にしました

満載に満たない分は 土場渡単価 × 数量 ＋ 最低保証の運賃。3ｔ車4,200円、4ｔ車4,500円（税抜）です。ダンプ1台を動かす以上、運賃はこの額を下回らない、という考え方ですね。

継ぎ目がぴったり合います。満載ちょうどで計算すると、この式は表の配達単価と1円も違わない金額になります。3ｔ車2.0㎥なら10,600円、4ｔ車2.5㎥なら12,500円。どちらの式で計算しても同じです。

40-0 の数量3ｔ車4ｔ車
0.1㎥4,520円4,820円
0.5㎥5,800円6,100円
1.0㎥7,400円7,700円
2.0㎥（3ｔ満載）10,600円10,900円
2.5㎥（4ｔ満載）13,250円12,500円

いずれも税抜。前の「常用 ÷ 7 ÷ 端数」で0.1㎥が43,177円になっていた破綻は、これで消えました。どの数量でも素直な金額が出ます。

しきい値は各車の満載量で確定

3ｔ車は2.0㎥未満、4ｔ車は2.5㎥未満で最低保証が効きます。数字で書いて、解釈の余地を消しました。

全数量で検算し、運賃相当額が保証額（3ｔ4,200円・4ｔ4,500円）を下回らないことを確認しています。4ｔ車の2.2㎥のような、以前は保証が抜けていた帯も塞がりました。

「敷いてから判断」も残しました

端数が出るご注文では、金額をお伝えしたうえで「まず満載の分だけお届けして、敷きならしてから足りるかご判断いただくこともできます」と選べるようにしました。追加のお届けには配達費用があらためてかかることも添えます。

前回は端数を計算せず電話に回していましたが、最低保証方式ならどの数量でも金額が出せます。断るのではなく、選んでいただく形にしてあります。

0.3㎥や0.1㎥だと、満載2.0㎥の10,600円より高くなってしまいます。そこで端数が0.5㎥未満のときは計算させず、お電話へ回すようにしました。下の確認事項をご覧ください。

10ｔ車（大型）6m以上本社で見積り

3ｔ車と4ｔ車の条件はお見積りフォームに書かれていたもの、10ｔ車の6mはご指示のとおりです。道幅6m以上か数量が多い場合は大型配達をご案内し、本社（019-638-7521）へ回します。金額は言わせず、4ｔ・3ｔの単価から推測することも禁じています。土場渡しのときは道幅の注釈を付けません。

大型の単価は、いま持たせていません

単価表には大型（6.0㎥積）の列もありました。ただ「大型は本社に回す」というご指示だったので、ボットの原稿からは外してあります。持っていると必ず口を滑らせるためです。答えさせたい場合は言ってください。

再生砕石の対応

再生路盤材40 ＝ RC-40〜0。残る B砕 は消去法で RC-80〜0 としました。ここだけは私の推測ですが、両方とも同じ単価なので、仮に逆でも請求額は変わりません。

ご注文と配車

ご注文のときにお客様に何を伝えてもらえばよいか、はっきりしていませんでした。日時・数量・場所の3点を案内するよう入れました。

ボットが案内する3点

お電話（019-638-7521 平日8:00〜17:00）で、ご希望の日時・数量・お届け先の場所をお伝えください。配車の都合を確認して、その場でお答えします。

あわせて「数量がまとまる場合は、配車の都合で何回かに分けてのお届けになることがあります」と伝えるようにしました。一度に全部届く前提で話が進むと、あとで困るのは現場です。

保有台数は持たせていません

3ｔ車1台・4ｔ車2台という台数は、ボットには入れていません。持たせると必ずそれを使って「2台で2往復すれば」といった勝手な配車計画を答え始めます。配車は砕石場が決めることです。

台数は wordpress/chatbot/price-sheet-notes.md に記録してあります。ボットに言わせたい場合は教えてください。

チャットの中にボタンを置ける場所がありました

HTMLを無理やり書き換える必要はありませんでした。AI Engine の Compliance Text という設定欄が、入力欄の下にHTMLをそのまま表示する作りになっています（.mwai-compliance）。ここにリンクを置けば、プラグインの構造に手を入れずに済みます。

/**
 * 石名坂：チャットの会話を、お問い合わせフォームの本文に引き継ぐ

 * 使い方は2つに分かれます。

 *   ・上のリンクが押されたら、その時点のチャットの会話を読み取って

 *   お問い合わせページへ移動します。「押しても何も起きない」状態にはなりません。
 *   AI Engine の更新でクラス名が変わったときは、この形で表に出ます。
 */

add_action( 'wp_footer', function () {

	if ( is_admin() ) {
		return;

<script id="izk-chat-to-form" data-noptimize="1">
(function () {
	'use strict';

	// AI Engine 側のクラス名。更新で変わったらここだけ直す
	var SEL_CONVERSATION = '.mwai-conversation';
	var SEL_MESSAGE      = '.mwai-reply';
	var CLASS_AI         = 'mwai-ai';
	var CLASS_USER       = 'mwai-user';

	var STORE_KEY   = 'izkChatTranscript';
	var LINK_CLASS  = 'izk-to-form';
	var CONTACT_PATH = '/contact/';
	var HEADING     = '──── チャットでのやりとり ────';

	function store() {
		try {
			return window.sessionStorage;
		} catch (e) {
			return null;
		}
	}

	/** チャットの会話を文章にする。読めなければ空文字を返す */
	function readTranscript() {
		var box = document.querySelector(SEL_CONVERSATION);
		if (!box) { return ''; }

		var nodes = box.querySelectorAll(SEL_MESSAGE);
		var lines = [];

		for (var i = 0; i < nodes.length; i++) {
			var el = nodes[i];
			var who;
			if (el.classList.contains(CLASS_USER)) {
				who = 'お客様';
			} else if (el.classList.contains(CLASS_AI)) {
				who = '案内係';
			} else {
				continue; // system や error は入れない
			}
			var text = (el.innerText || el.textContent || '')
				.replace(/\u00a0/g, ' ')
				.replace(/[ \t]+\n/g, '\n')
				.replace(/\n{3,}/g, '\n\n')
				.trim();
			if (text) {
				lines.push(who + '：' + text);
			}
		}

		// お客様の発言が1つもなければ、引き継ぐ意味がない
		var hasUser = lines.some(function (l) { return l.indexOf('お客様：') === 0; });
		if (!hasUser) { return ''; }

		return lines.join('\n\n');
	}

	/** 本文欄に収まる長さに整える。古いやりとりから削る */
	function fit(transcript, room) {
		var head = HEADING + '\n\n';
		var tail = '\n\n──── ここまで ────';
		var budget = room - head.length - tail.length;
		if (budget < 200) { return ''; }

		if (transcript.length > budget) {
			var note = '（前半のやりとりは省略しています）\n\n';
			transcript = note + transcript.slice(transcript.length - (budget - note.length));
		}
		return head + transcript + tail;
	}

	// ── 1. リンクが押されたら会話を保存する ────────────────
	document.addEventListener('click', function (ev) {
		var link = ev.target && ev.target.closest
			? ev.target.closest('a.' + LINK_CLASS)
			: null;
		if (!link) { return; }

		var s = store();
		if (!s) { return; }           // 保存できなくても、リンクとしては動く

		var transcript = readTranscript();
		try {
			if (transcript) {
				s.setItem(STORE_KEY, transcript);
			} else {
				s.removeItem(STORE_KEY);
			}
		} catch (e) { /* 保存できなければ、そのまま移動する */ }
	}, true);

	// ── 2. お問い合わせページで本文欄に貼り付ける ──────────
	function paste() {
		if (location.pathname.indexOf(CONTACT_PATH) !== 0) { return; }

		var s = store();
		if (!s) { return; }

		var transcript;
		try {
			transcript = s.getItem(STORE_KEY);
		} catch (e) { return; }
		if (!transcript) { return; }

		var field = document.querySelector('textarea[name="your-message"]');
		if (!field) { return; }

		try { s.removeItem(STORE_KEY); } catch (e) {}

		var max = parseInt(field.getAttribute('maxlength'), 10);
		if (!max || max < 1) { max = 2000; }

		var before = field.value || '';
		var room = max - before.length - (before ? 2 : 0);
		var block = fit(transcript, room);
		if (!block) { return; }

		var after = before ? (before.replace(/\s+$/, '') + '\n\n' + block) : block;
		field.value = after;
		field.dispatchEvent(new Event('input', { bubbles: true }));

		notice(field, before);
	}

	/** 貼り付けたことを知らせる。元に戻せるようにする */
	function notice(field, previous) {
		if (document.getElementById('izk-paste-notice')) { return; }

		var box = document.createElement('div');
		box.id = 'izk-paste-notice';
		box.setAttribute('role', 'status');
		box.style.cssText = 'margin:12px 0;padding:12px 14px;border-left:4px solid #b34a18;'
			+ 'background:#f6e5db;color:#25231e;font-size:14px;line-height:1.7;border-radius:2px;';

		var msg = document.createElement('span');
		msg.textContent = 'チャットでのやりとりを、下の「お問い合わせ内容」に貼り付けました。'
			+ '内容をご確認のうえ、必要なところを書き足して送信してください。';
		box.appendChild(msg);

		var undo = document.createElement('button');
		undo.type = 'button';
		undo.textContent = '貼り付けをやめる';
		undo.style.cssText = 'margin-left:10px;padding:4px 12px;font:inherit;font-size:13px;'
			+ 'border:1px solid #b34a18;background:#fff;color:#b34a18;border-radius:2px;cursor:pointer;';
		undo.addEventListener('click', function () {
			field.value = previous;
			field.dispatchEvent(new Event('input', { bubbles: true }));
			box.remove();
		});
		box.appendChild(undo);

		// 「お問い合わせ内容」の見出しの上に出す。段落の外に置いて、体裁を崩さない
		var label = field.id ? document.querySelector('label[for="' + field.id + '"]') : null;
		var anchor = (label && label.closest('p'))
			|| field.closest('p')
			|| field.closest('.wpcf7-form-control-wrap')
			|| field;
		anchor.parentNode.insertBefore(box, anchor);
		if (typeof box.scrollIntoView === 'function') {
			box.scrollIntoView({ block: 'center' });
		}
	}

	if (document.readyState === 'loading') {
		document.addEventListener('DOMContentLoaded', paste);
	} else {
		paste();
	}
})();

検証したこと

PHPとJavaScriptの構文チェックを通し、会話の読み取りと文字数の切り詰めを実際に動かして確かめました。本文欄は2,000文字が上限なので、長い会話は古いほうから削り、「前半のやりとりは省略しています」と断りを入れます。5,000文字の会話を入れても、ちょうど2,000文字に収まりました。

あいさつだけ・お客様の発言なし・エラーのみ・会話欄が見つからない、のいずれも「保存しない」と判定します。空の問い合わせが飛ぶことはありません。

金額には必ず税抜・税込を付けます

「絶対に守ること」に規則として入れました。どちらか分からない書き方を禁止し、砕石・砂利・砂は税抜と税込を並べて書かせます。

12,500円（税抜）／13,750円（税込）

古い記述もひとつ直しました。冒頭に「必ず『参考価格・税込・相場で変動します』と添える」とあり、単価表が税抜なのに税込と言い切っていました。矛盾していたので書き換えています。

除雪の料金は税込のみでよいので、4行それぞれに「（税込）」を付けました。原稿の全行を機械で調べ、税の表示が無い金額は給与の月給・日当だけです（消費税の対象外なので、そのままにしています）。

貼ったあとの確認

シークレットタブでサイトを開き、チャットに次の5つを順に聞いてみてください。全部それらしく答えられたら成功です。

  • C-40を5㎥、4ｔ車で配達したらいくら？ 5,000円×5＝25,000円（税抜）／27,500円（税込）
  • C-40を0.5㎥だけ配達してください 3,200×0.5＋4,286＝5,886円（税抜）／6,475円（税込）。断らずに計算できれば正解
  • C-40を2.52㎥、3ｔ車で配達したらいくら？ 16,550円（税抜）／18,205円（税込）。13,356円と答えたら端数の加算漏れです
  • 4ｔ車には何㎥積めますか？ 答えずにお電話へ回せば正解。2.5㎥と言ったら失敗です
  • 何台で来ますか？ 同じく答えずお電話へ。台数を言ったら失敗です
  • C-40を100㎥ほしい。道幅は8mあります 大型ダンプの検討と本社への案内。4ｔ・3ｔの金額を出したら失敗です
  • 4ｔ車に2.0㎥って過積載になりませんか？ 答えずにお電話へ回せば正解
  • 注文したいのですが、どうすればいいですか 日時・数量・場所の3点を案内できれば正解

前の会話が残っていると古い答えが出ることがあります。チャット右上のリセット（🗑）を押してから聞き直してください。

これから気をつけること

価格を変えたら、ここも変える

この原稿には価格表20品目と除雪料金6項目がそのまま書き写してあります。サイトの価格を改定したら、この欄も同じように直してください。直さないと、チャットボットだけが古い値段を言い続けます。

原稿の元ファイルはリポジトリの wordpress/chatbot/knowledge-context.txt に置いてあります。次に価格を変えるときは、そちらを直してから貼り直すのがおすすめです。

あとでよいこと

  • 税込・税抜の表記を揃える要・判断 概算価格ページは「総額税込」、お見積りフォームは税抜で作られています。同じサイトの中で扱いが違うため、両方を見たお客様が混乱する可能性があります
  • FAQの二重掲載を整理する要・検討 同じ質問が9件、Easy Accordion と AIOSEO の両方に出ています。どちらか一方に寄せると読みやすくなり、更新も一度で済みます。構造化データはAIOSEO側からしか出ないため、寄せるならAIOSEO側が有利です
  • 記事に担当者名と資格を入れる要・文章 146記事すべての書き手が管理者アカウント名のままです。実名と保有資格が入ると、記事の信頼性が上がります
