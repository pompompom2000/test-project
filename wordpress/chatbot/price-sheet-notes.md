# 価格表（V6）の読み方メモ

チャットボットの原稿（`knowledge-context.txt`）を作るときに調べた、価格表の仕組みの記録。
次に価格を改定する人が、同じことを調べ直さなくて済むように残す。

## 価格の組み立て

価格表は、1㎥あたりの土場渡単価（税別）を出発点に、次の順で総額を出している。

```
配達単価（1㎥）＝ 土場渡単価（1㎥）＋ 運賃（1㎥）
運賃（1㎥・税別）＝ 3ｔ車 2,100円 ／ 4ｔ車 1,800円
総額（税込）＝ 単価 × 積込量 × 1.10
積込量（価格算出の基礎）＝ 3ｔ車 2.0㎥ ／ 4ｔ車 2.5㎥
```

この式で、公開している概算価格ページの総額が19品目すべて再現できる。

## 「７回で」の意味

価格表の注記にある「※標準15kmまで ７回で」の**7回は、15km圏を1日に回れる回数**。
運賃（3ｔ車2,100円／4ｔ車1,800円）は、この回転数を前提に決まっている。

だから注記は「15kmまで・1日7回転を標準とし、それを下回る条件（積込が2.0㎥/2.5㎥未満、
距離が15km超）なら砕石場に確認」という意味になる。

## 公表する積込量は 1.5㎥ / 2.0㎥

| | 価格算出の基礎 | 公表値 |
|---|---|---|
| 3ｔ車 | 2.0㎥ | **1.5㎥** |
| 4ｔ車 | 2.5㎥ | **2.0㎥** |

公表値のほうを使う。**厳密に過積載ではないかと問われた場合に、会社として答える数字がこちら**のため。
サイトの概算価格ページとお見積りフォームも、1.5㎥／2.0㎥で書かれている。

総額（13,750円など）はどちらの見方でも同じなので、お客様の支払額は変わらない。

## チャットボットに入れていないもの、とその理由

- **1㎥あたりの単価**（土場渡・配達とも）
  公表値の2.0㎥で計算すると総額に届かない。4ｔ車なら 5,500 × 2.0 ＝ 11,000 で、
  公開値 13,750 と食い違う。1㎥単価は2.5㎥前提の数字なので、併記すると矛盾する。
  原稿では「1㎥いくら」と答えること自体を禁止し、1台あたりの総額だけを持たせている。
- **積込量 2.0㎥ / 2.5㎥**、**運賃の1㎥単価**、**1日7回転**
  いずれも原価の前提で、お客様に必要な情報ではない。上と同じ理由で外している。
- **積載量の法令判断**
  過積載かどうかを聞かれても答えず、本社（019-638-7521）に回す指示を入れている。

## 未確定のまま残していること

- **`B砕` と `再生路盤材40`** のどちらが、サイトの RC-80〜0 / RC-40〜0 に当たるか。
  価格表からは判断できない。両方 2,700円/㎥ で同額のため金額に影響はない。
  原稿では「2種類あり価格は同じ」と伝え、砕石場に確認していただく形にしている。
- **山土・砕砂** は砕石販売ページに品目としてあるが、価格表にも見積りフォームにも金額がない。
  原稿では電話に回している。

## 価格表にあってサイトにない規格

`80-40` と `砂利` の2つ。概算価格ページは20行だが、価格表は21規格ある。
原稿には21規格すべて入れているので、チャットボットはこの2つにも答えられる。

## 価格を改定したときにやること

1. この価格表を更新する。
2. `knowledge-context.txt` の「■ 価格表」の21行を差し替える。1台あたりの総額（税込）のみ。
3. サイトの概算価格ページと、お見積りフォーム（Forminator フォームID 1654）も直す。
4. 直し忘れると、チャットボットだけが古い値段を言い続ける。
