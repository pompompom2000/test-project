## 公開前の6つ、自己点検の結果

### ① 言い切っていないか

この題材は言い切りの誘惑が強い。意識して外したもの。

| 書きたくなる形 | 実際に書いた形 |
|---|---|
| すべての答えを同時に計算する | **これは、正しくありません**／間違いを消す機械 |
| 0と1が同時 | 0と1の混ぜ方そのものが状態。**位相を落とすと速い理由が説明から抜ける** |
| 量子もつれで瞬間通信 | **通信不可能定理。**相関はあるが合図は送れない |
| 絶対零度に冷やす機械 | **10ミリケルビン程度。**絶対零度には到達できない。**かつ超電導方式に限る** |
| トポロジカル量子ビットが実現した | Nature編集部が「証拠を示すものではない」と注記。**決着していない** |
| ○年に実用化される | **2029年（自社目標）／2035年（暗号移行）／2050年（ムーンショット）／「来ない」** の幅で示した |
| NECが撤退した | **報じられた。**NEC自身は「撤退」と言っていない |
| 日本は脱落した | **同じ月に理研・阪大が144量子ビット機を稼働**させている |

比喩は「どこから嘘になるか」を本文に書いた。
- 彫刻 → **彫刻家は完成形を知っているが、設計者が知るのは削り方だけ**
- 双子 → **使わなかった。**Bell不等式の破れが否定した描像で、2022年のノーベル賞を真逆に説明することになる（本文でその旨を明記）
- 迷路・並行世界・2ⁿのメモリ → **一切使わなかった**

### ② 自社の他の記述と食い違っていないか

`claude-code-05-safety`（第5回 注意点）と矛盾しない。第5回は
「AIが誤った内容を出力する可能性はある／最終確認は人が行う」。
この2本も「発表と、確かめられたことは違う」という同じ姿勢で通している。

前回の `ai-web3` の記事とも整合。あちらで「企業の発表をそのまま事実にしない」
と書いた線を、こちらでも守っている。

### ③ 他社のことを断定していないか

**この記事でいちばん神経を使った項目。**

- **NEC**：「撤退した」と書かず「報じられた」で通した。NEC自身は
  「コメントは差し控える」としており、認めても否定してもいない。
  経営判断への評価（「出遅れた」など）は一切書いていない。
- **Microsoft**：「嘘をついた」とは書かない。
  **「会社の発表は『できた』と言い、掲載誌の編集部は『証拠にはなっていない』と書いた」**
  という、両方の事実を並べる書き方にした。
- **D-Wave**：反論があった事実と、**同社が再反論している**ことを両方書いた。
- 「すべての発表が怪しいわけではない」と明記し、査読を通ったGoogleの例を挙げた。
- **「量子」を冠した商品**：公的な処分が一件も見つからなかったので、
  特定の商品名・会社名を一切出していない。

### ④ 数字と引用に出どころがあるか

出典は前編16・後編24。本文の数字はすべて出典付き。
**複数の出典が一致しなかった数字は、下記のとおり全部落とした。**

### ⑤ 法令・規格は原典を見たか

**見ていない。**この環境から go.jp・nature.com・nikkei.com・itmedia は開けない。
有料記事（日経・ダイヤモンド）の本文も一切読めていない。

そのため、
- 条文番号は**一つも書いていない**
- 論文は**題名・誌名・巻号・年**まで（本文の引用はしない）
- Nature編集部の注記だけは、**Science・Physics World・The Quantum Insider が
  独立に同じ文言を報じている**ため採用した

**公開前に、出典のURLをそちらで開いて確認してください。**

### ⑥ 人が特定されないか

出てくる個人は、**公表された研究者・受賞者・企業の最高経営責任者のみ**。
NECから富士通へ移ったとされる研究者は、**人数も氏名も公表されていない**ので
「研究者の多くが移ったと報じられている」にとどめた。

## 2026年9月14日 改稿（2回目）

石名坂から「何の分野で有効・活用できるのかが分かりにくい。セキュリティのため？」
という指摘。**この読まれ方は危ないので、正面から否定する節を立てた。**

### 直した中身

1. **「セキュリティのための機械ではない」節を新設（後編）**
   量子コンピュータは暗号を**壊す側**。2035年の切り替えは守る側の話であって、
   量子コンピュータが守ってくれるわけではない。
   あわせて **耐量子暗号（普通のPCで動く）** と **量子暗号＝量子鍵配送（専用設備）**
   を分け、**どちらも量子コンピュータの使い道ではない**と明記した。

2. **本命＝分子と材料のシミュレーション、を前編・後編の両方に入れた**
   前編に「もうひとつ、圧倒的に得意なことがあります」を新設。
   **分子の中の電子も矢印を持っている**ので、普通のコンピュータで計算すると
   量子ビットのときと同じ爆発が起きる。だから量子で真似するのが素直
   ── これが **1981年にファインマンが量子コンピュータを言い出した動機**。
   暗号の話（1994年）はそのあとに出てきたもの。

3. **具体例を1つ置いた（後編）**
   ハーバー・ボッシュ法は400〜500度・数百気圧で、人類が使う全エネルギーの
   数パーセントを消費する。ところが**根粒菌のニトロゲナーゼは常温常圧で
   同じことをしていて、しくみが未解明。** 2017年のPNAS論文が、量子コンピュータで
   解ける可能性を論じている。**畑をやる読者に通じる例**として選んだ。

4. **分野ごとの一覧表を追加（後編）**
   分子・材料／暗号解読／組合せ最適化／金融／AI／日常の事務、の6行。
   それぞれ「いまの状況」を証拠の強さつきで書いた。

5. **「私たちの業界は、どうか」を新設（後編）**
   建設・土木・砕石での活用例を調べたが**見つからなかった**と正直に書いた。
   セメント・コンクリートの材料研究に量子を使った例も確認できず。
   「理屈のうえでは将来つながる可能性はあるが、いまは確認できていない」まで。

6. 重複した「何がすごくないのか」の節を、表と噛み合う形に詰め直した。
   振動ローラーのたとえ（転圧では代わりがきかないが、柱は立てられない）を入れた。
