本命 ／ 画像を添付して使う

01見本を渡して、絵を足してもらう

こちらで作った図を添付し、「文字と配置はそのまま、イラストだけ足して」と頼む形です。文字が崩れる余地がいちばん小さく、気候変動シリーズの図に近い見た目になります。

添付した画像と同じ構成・同じ文字で、日本語のインフォグラフィックを1枚描き直してください。

【そのまま守ってほしいこと】
・書かれている文字は、一字一句そのまま。数字も変えない。
・上下の並び（見出し帯 → 左右2つの箱 → 矢印 → 緑の結論 → 灰色の帯）を変えない。
・左の箱はオレンジ、右の箱は青、結論は緑、いちばん下は灰色。

【足してほしいこと】
・各項目の横に、内容に合った平たいイラストを小さく添える。
　左の箱にはトラックと荷物、右の箱にはヘルメットをかぶった作業員と時計、
　緑の結論には走るトラック、灰色の帯には宅配ボックス・荷台・腕時計。
・イラストは線が太めの、親しみのある平面的な絵柄。写真のような立体感は出さない。
・枠線は太めにして、手描きに近い温かみを少しだけ出す。

【条件】
・画像に書かれている文字以外の文字を、新しく描き足さないこと。
・官公庁の紋章・印章・ロゴを描かない。公式の配布資料に見えるデザインにしない。
・実在する企業名やロゴを描かない。人物の顔は簡略化した絵柄にとどめる。
・アスペクト比 16:9 の横長。
文章だけで頼む

02ゼロから組んでもらう

見本が手元にないときの全文です。長いですが、描く文字をすべて書き出してあるので、そのまま貼れば形になります。

日本語のインフォグラフィックを1枚描いてください。記事を読まない人でも、この1枚で要点が伝わる「まとめ図」です。

【全体の構成】上から順に
1. 見出しの帯
2. 左右に並んだ2つの箱（左はオレンジ枠、右は青枠）
3. 2つの箱から下向きの太い矢印が2本、中央に集まる
4. 緑の枠の結論ボックス（横長）
5. いちばん下に灰色の帯（3項目を横並び）

【描く文字（この通りに、誤字なく）】

■ 見出しの帯
「総合物流施策大綱 ── 国が決めた、物流の5年計画（2026〜2030年度）」

■ 左の箱（オレンジ）見出しは吹き出しの形で「荷物が、運べなくなる」
・「2030年度に 約34%の輸送力が不足する」
　　小さく「対策を何もしなかった場合の推計」
・「そのうち 約14%は、すでに克服」
　　小さく「「2024年問題」への官民の取組による」
・「ただし、荷物そのものも約12%減った」
　　小さく「28.4億トン（2019年）→ 25.1億トン（2024年）」

■ 右の箱（青）見出しは吹き出しの形で「運ぶ人が、足りない」
・「大型ドライバーの年収 492万円」
　　小さく「全産業の平均は527万円」
・「労働時間は年 2,484時間」
　　小さく「全産業の平均は2,052時間。年400時間以上も長い」
・「15〜29歳は、わずか 10.1%」
　　小さく「若い人が入ってこない」

■ 緑の結論ボックス
大きく「だから国は、賃金と労働時間を『全産業平均まで』と書いた」
小さく「2030年度までが「集中改革期間」。物流を、続けられる仕事にする5年間」

■ 灰色の帯
中央に「受け取る私たちにも、できることがある」
その下に3つ横並び
・「置き配・宅配ボックス」／小さく「利用率 25.6% → 50%程度へ」
・「トラックの積載効率」／小さく「41.3% → 44%へ」
・「荷待ち・荷役の時間」／小さく「年750時間 → 年625時間へ」

【絵柄】
・太めのゴシック体。数字は特に大きく、色を変えて目立たせる。
・角丸の枠、太い枠線。親しみのある平面的なイラストを各項目の横に小さく添える
　（トラック、荷物の箱、時計、ヘルメットの作業員、宅配ボックス）。
・色は4色まで。オレンジ、青、緑、灰色。背景は白。

【条件】
・上に挙げた文字以外の文字を一切描かないこと。意味のない英字や記号の飾りを入れない。
・官公庁の紋章・印章・ロゴを描かない。公式の配布資料に見えるデザインにしない。
・実在する企業名やロゴを描かない。
・アスペクト比 16:9 の横長。
直したいとき

03一部だけ描き直してもらう

全体は良いのに1か所だけ字が崩れた——というときに使います。作り直すより、直す場所を指して頼むほうが早く決まります。

いまの画像の、次の部分だけを直してください。ほかは一切変えないでください。

・直す場所：（例）右の箱の2つ目「労働時間は年 2,484時間」
・直したあとの文字：労働時間は年 2,484時間

文字は太めのゴシック体で、はっきりと。ほかの文字、配置、色、イラストは
いまのままにしてください。

出てきたら、まず数字を1つずつ確かめてください。この6つが崩れやすいところです。

  • 34% と 14% ── 入れ替わっていないか
  • 28.4億トン → 25.1億トン ── 桁と小数点
  • 492万円 と 527万円 ── どちらが全産業か
  • 2,484時間 と 2,052時間 ── カンマの位置
  • 10.1% ── 小数点
  • 41.3% → 44%、750 → 625、25.6% → 50% ── 矢印の向き

この会話に貼っていただければ、こちらで1字ずつ突き合わせます。
