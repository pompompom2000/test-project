<h2 class="wp-block-heading">中長期計画書・定期報告書の記載事例集</h2>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>2026年４月の物流効率化法の全面施行により、特定荷主及び特定連鎖化事業者（以下、「特定荷主等」という。）において、中長期計画書（様式第３）及び定期報告書（様式第５）の作成・提出が義務付けられます。　そこで、特定荷主等が作成・提出する中長期計画書及び定期報告書の参考資料として記載事例集を作成しました。　製造業、卸売業、小売業及び連鎖化事業者の４種類ごとに、それぞれ「取組が進んでいる企業向け」、「これから取組を深める企業向け」の２つの記載例を提示していますので、自社の実態に合わせて、参考として活用してください。</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>あくまで参考になりますので、これを読み解きながら、自社の現状などを把握し、将来を見据えて、書いてください</p>
<!-- /wp:paragraph -->

<script>
let clickCount = 0;
let isRunning = false; // 大群が走っている最中かどうかを判定するフラグ

function catMagicClick() {
  // もし大群が走っている最中なら、クリックを無視する（重くなるのを防ぐ）
  if (isRunning) return; 

  const pattern = clickCount % 3;
  
  if (pattern === 0) {
    releaseCats('left-to-right');
  } else if (pattern === 1) {
    releaseCats('right-to-left');
  } else if (pattern === 2) {
    releaseCats('top-to-bottom');
  }
  
  clickCount++;
}

function releaseCats(direction) {
  isRunning = true; // 大群発生スタート！追加クリックを禁止する

  const container = document.getElementById('cat-horde-container');
  // ▼ ここに通常の大群用の猫のURLを貼り付け ▼
  const catUrl = 'https://www.ishinazaka.co.jp/common/files/uploads/2026/04/ezgif.com-animated-gif-maker.gif'; 
  
  // ★ ▼ ここに【一匹だけ混ぜる別の生き物】のGIF画像のURLを貼り付け ▼ ★
  const otherImageUrl = 'https://www.ishinazaka.co.jp/common/files/uploads/2026/04/1775735437402.png'; 

  const catCount = 20; // 猫の数

  // 大群（catCount匹）の中から、ランダムに「一匹」を選ぶ
  const otherIndex = Math.floor(Math.random() * catCount);

  for (let i = 0; i < catCount; i++) {
    setTimeout(() => {
      const cat = document.createElement('div');
      cat.className = 'horde-cat';

      // 通常は猫の画像、選ばれた一匹だけ別の生き物の画像にする
      if (i === otherIndex) {
        cat.style.backgroundImage = `url('${otherImageUrl}')`;
      } else {
        cat.style.backgroundImage = `url('${catUrl}')`;
      }

      const size = Math.floor(Math.random() * 70) + 50; // サイズもランダム
      cat.style.width = `${size}px`;
      cat.style.height = `${size}px`;

      const duration = (Math.random() * 2.5) + 1.5; // 速度もランダム

      if (direction === 'left-to-right') {
        cat.style.top = `${Math.floor(Math.random() * 90)}vh`;
        cat.style.left = '-200px';
        cat.style.transform = 'scaleX(1)'; // 右向き
        cat.style.animation = `horde-run-lr ${duration}s linear forwards`;
      } else if (direction === 'right-to-left') {
        cat.style.top = `${Math.floor(Math.random() * 90)}vh`;
        cat.style.right = '-200px';
        cat.style.transform = 'scaleX(-1)'; // 左向き
        cat.style.animation = `horde-run-rl ${duration}s linear forwards`;
      } else if (direction === 'top-to-bottom') {
        cat.style.left = `${Math.floor(Math.random() * 95)}vw`;
        cat.style.top = '-200px';
        const flip = Math.random() > 0.5 ? 1 : -1; // 落ちるときは向きもランダム
        cat.style.transform = `scaleX(${flip})`;
        cat.style.animation = `horde-fall-tb ${duration}s linear forwards`;
      }

      container.appendChild(cat);

      setTimeout(() => {
        cat.remove(); // 走り終わった猫を消去
      }, duration * 1000);

    }, Math.random() * 1500); // 出現のバラつき
  }

  // 大群が全員走り終わるころ（約4.5秒後）に、クリック禁止を解除する
  setTimeout(() => {
    isRunning = false;
  }, 4500);
}
</script>

<h2 class="wp-block-heading"><strong>建設業にも適用される！</strong></h2>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>改正物流総合効率化法に基づき、前年度の貨物輸送量が年間9万トン以上の荷主は「特定荷主」に指定され、2026年4月から中長期計画の提出、物流統括管理者の選任、定期報告が義務化されます。建設業において資材（鉄骨、砂利など）の大量輸送を行う企業が主な対象となり、対応しない場合、罰則（50万円以下の罰金）の可能性があります。&nbsp;</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>建設業における特定荷主の定義とポイント</p>
<!-- /wp:paragraph -->

<!-- wp:list -->
<ul class="wp-block-list"><!-- wp:list-item -->
<li><strong>特定荷主の基準:</strong>&nbsp;トラック運送事業者を利用した貨物輸送量が、前年度年間9万トン以上。</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>対象となる建設関連貨物:</strong><!-- wp:list -->
<ul class="wp-block-list"><!-- wp:list-item -->
<li>建設資材（鉄骨、砂利、砂、砕石、セメント、生コンクリート、合材など）。</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li>工事現場への直接搬入、および一次ストックヤードへの移動を含む。</li>
<!-- /wp:list-item --></ul>
<!-- /wp:list --></li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>義務化の内容 (2026年4月〜):</strong><!-- wp:list -->
<ul class="wp-block-list"><!-- wp:list-item -->
<li><strong>物流統括管理者の選任:</strong>&nbsp;物流に関する責任者を配置。</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>中長期計画の作成・提出:</strong>&nbsp;物流効率化に向けた計画。</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>定期報告:</strong>&nbsp;前年度の取組状況を報告。</li>
<!-- /wp:list-item --></ul>
<!-- /wp:list --></li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>努力義務 (2025年4月〜):</strong>&nbsp;全ての荷主に積載率向上、荷待ち時間の短縮、荷役時間短縮が努力義務化。</li>
<!-- /wp:list-item --></ul>
<!-- /wp:list -->

<!-- wp:paragraph -->
<p>建設業者がすべき対策</p>
<!-- /wp:paragraph -->

<!-- wp:list {"ordered":true} -->
<ol class="wp-block-list"><!-- wp:list-item -->
<li><strong>輸送量の把握:</strong>&nbsp;自社の前年度運送量を算定する（9万トンが基準）。</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>物流体制の見直し:</strong>&nbsp;建設資材の配送業者と連携し、荷待ち時間の削減、積載効率向上に取り組む。</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>計画の策定:</strong>&nbsp;2026年4月からの本格運用に向け、計画を作成。&nbsp;</li>
<!-- /wp:list-item --></ol>
<!-- /wp:list -->

<!-- wp:paragraph -->
<p>詳細は「特定荷主の物流効率化法への対応の手引き」を参照してください。&nbsp;</p>
<!-- /wp:paragraph -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading">罰則例は、以下のとおり</h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>荷主は、以下のいずれかに該当する場合には、罰則が科されます。</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p><br>以下に該当する場合は50万円以下の罰金<br>・特定荷主の指定基準重量を上回る荷主が、特定荷主の指定に係る届出を行わない又は虚<br>偽の届出をした場合（法第 76 条第１号）<br>・中長期計画を提出しない場合（法第 76 条第２号）<br>・定期報告を行わない又は虚偽の届出をした場合（法第 76 条第３号）<br>・報告徴収の際に報告をしない又は虚偽の報告をした場合（法第 76 条第４号）<br>・立入検査を拒み、妨げ、又は忌避した場合（法第76条第４号）</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p><br>以下に該当する場合は20万円に以下の過料<br>・物流統括管理者の選任・解任の届出を行わない又は虚偽の届出をした場合（法第 80 条）</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p><br>以下に該当する場合は100万円以下の罰金<br>・命令に違反した場合（法第 75 条第１号）<br>・特定荷主が物流統括管理者を選任しない場合（法第75条第２号）</p>
<!-- /wp:paragraph -->
