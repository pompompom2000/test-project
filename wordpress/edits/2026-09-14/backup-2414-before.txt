<h2 class="wp-block-heading has-medium-font-size"> ちょっとした 防犯 意識で変わってくる</h2>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>最近、空き巣などの 防犯 が必要性のある物騒なニュースや、住宅街へのクマ出没のニュースが多く、不安を感じている方も多いのではないでしょうか？</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>「手軽にできる対策はないかな…」と考えている方に、石名坂がおすすめしたいのが「家の周り（犬走り）に、5号砕石を敷き詰めること」です！</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>実はこれ、防犯対策としてはもちろん、野生動物の侵入対策としても非常に効果的なんです。今回は、なぜ5号砕石がおすすめなのか、その理由と敷き方のコツをプロの目線で分かりやすく解説します！</p>
<!-- /wp:paragraph -->

<!-- wp:heading {"level":4,"fontSize":"medium"} -->
<h4 class="wp-block-heading has-medium-font-size">1. なぜ「5号砕石」が防犯やクマ対策に効くのか？</h4>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>5号砕石（単粒度砕石）とは、大きさが13mm〜20mmくらい（10円玉〜100円玉くらい）に揃えられた、角張った石のことです。</p>
<!-- /wp:paragraph -->

<!-- wp:image {"id":608,"width":"200px","sizeSlug":"large","linkDestination":"none","align":"center"} -->
<figure class="wp-block-image aligncenter size-large is-resized"><img src="https://www.ishinazaka.co.jp/common/files/uploads/2025/12/５号-1024x768.jpg" alt="５号砕石のアップ写真" class="wp-image-608" style="width:200px"/></figure>
<!-- /wp:image -->

<!-- wp:paragraph -->
<p>この石の上を歩くと、石と石がこすれ合って<strong>「ジャリッ！ジャリッ！」とかなり大きな音</strong>が鳴ります。</p>
<!-- /wp:paragraph -->

<!-- wp:list -->
<ul class="wp-block-list"><!-- wp:list-item -->
<li><strong>空き巣対策：</strong> 泥棒は「音」を最も嫌います。窓に近づく前に足音が鳴る家は、それだけでターゲットから外されやすくなります。</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>クマ・獣害対策：</strong> クマなどの野生動物も警戒心が強いため、自分の足音が大きく鳴る場所を嫌がります。ただ、生ゴミや果実など「食べ物の匂い」の魅力が勝ってしまえば、足音など気にせずに敷地内に侵入してきます。しかしながら、万が一敷地内に侵入された場合でも、家の中にいて「ジャリッ」という足音で異変にいち早く気づくことができます。あくまでも敷地内に侵入したことを確認するという意味になります。</li>
<!-- /wp:list-item -->

<script>
let clickCount = 0;
let isRunning = false;

function catMagicClick() {
  if (isRunning) return; 

  clickCount++;

  // ★ 5回に1回、肉球スタンプを出す
  if (clickCount % 5 === 0) {
    showPawStamp();
  }

  // ★ ご希望の3パターンループ（左→右、右→左、上→下）
  const pattern = (clickCount - 1) % 3;
  if (pattern === 0) {
    releaseCats('left-to-right'); // 1回目
  } else if (pattern === 1) {
    releaseCats('right-to-left'); // 2回目
  } else if (pattern === 2) {
    releaseCats('top-to-bottom'); // 3回目
  }
}

function showPawStamp() {
  const container = document.getElementById('cat-horde-container');
  const stamp = document.createElement('div');
  stamp.className = 'paw-stamp-overlay';
  container.appendChild(stamp);
  setTimeout(() => { stamp.remove(); }, 2000);

function releaseCats(direction) {
  isRunning = true;
  const container = document.getElementById('cat-horde-container');
  const catUrl = 'https://www.ishinazaka.co.jp/common/files/uploads/2026/04/ezgif.com-animated-gif-maker.gif'; 
  
  // ★ ▼ ここに一匹だけ混ぜる別の生き物のURLを貼り付け ▼ ★
  const otherImageUrl = 'https://www.ishinazaka.co.jp/common/files/uploads/2026/04/ezgif.com-animated-gif-maker.gif'; 

  // ★ 迫力と滑らかさを両立する「50匹」に設定
  const catCount = 100; 
  const otherIndex = Math.floor(Math.random() * catCount);

  for (let i = 0; i < catCount; i++) {
    // ★ 渋滞解消：3.5秒かけてパラパラと分散して出現させる
    const delay = Math.random() * 3500;

    setTimeout(() => {
      const cat = document.createElement('div');
      cat.className = 'horde-cat';
      
      // 画像の振り分け
      if (i === otherIndex) {
        cat.style.backgroundImage = `url('${otherImageUrl}')`;
      } else {
        cat.style.backgroundImage = `url('${catUrl}')`;
      }

      // サイズ設定（遠近感を出す）
      const size = Math.floor(Math.random() * 70) + 40;
      cat.style.width = `${size}px`;
      cat.style.height = `${size}px`;

      // 速度設定（2秒〜4.5秒）
      const duration = (Math.random() * 2.5) + 2.0;
      let startX, startY, endX, endY, flip;

      // ==========================================
      // ★ 点ではなく「範囲（エリア）」から出現させる計算
      // ==========================================
      if (direction === 'left-to-right') {
        // 左側の範囲から右側の範囲へ
        startX = -20 - Math.random() * 30; // 画面左外（-20vw 〜 -50vw）
        startY = Math.random() * 90;       // 高さの範囲（0vh 〜 90vh）バラバラ
        endX = 110 + Math.random() * 30;   // 画面右外へ
        endY = startY + (Math.random() * 20 - 10); // 真横ではなく少し上下にブレながら走る
        flip = 1; // 右向き
        
      } else if (direction === 'right-to-left') {
        // 右側の範囲から左側の範囲へ
        startX = 110 + Math.random() * 30; // 画面右外（110vw 〜 140vw）
        startY = Math.random() * 90;       // 高さの範囲（0vh 〜 90vh）
        endX = -20 - Math.random() * 30;   // 画面左外へ
        endY = startY + (Math.random() * 20 - 10); 
        flip = -1; // 左向き
        
      } else if (direction === 'top-to-bottom') {
        // 上の範囲から下の範囲へ
        startX = Math.random() * 95;       // 横幅の範囲（0vw 〜 95vw）バラバラ
        startY = -20 - Math.random() * 30; // 画面上外（-20vh 〜 -50vh）
        endX = startX + (Math.random() * 20 - 10); // 真下ではなく少し左右にブレながら降る
        endY = 110 + Math.random() * 30;   // 画面下外へ
        flip = Math.random() > 0.5 ? 1 : -1; // 落ちるときは左右ランダム
      }

      container.appendChild(cat);

      // 最軽量のアニメーション処理（GPU駆動）
      cat.animate([
        { transform: `translate3d(${startX}vw, ${startY}vh, 0) scaleX(${flip})` },
        { transform: `translate3d(${endX}vw, ${endY}vh, 0) scaleX(${flip})` }
      ], {
        duration: duration * 1000,
        easing: 'linear',
        fill: 'forwards'
      });

      // 走り終わったら削除
      setTimeout(() => {
        cat.remove();
      }, duration * 1000);

    }, delay); 
  }

  // 大群が全員走り終わるまで（出現3.5秒＋移動約4.5秒 ＝ 約8秒）次のクリックを待つ
  setTimeout(() => {
    isRunning = false;
  }, 8000);
}

<h4 class="wp-block-heading has-medium-font-size">2. ホームセンターの「防犯砂利」とどう違うの？</h4>

<p>ホームセンターに行くと、白いガラス製などの「防犯砂利」が売られています。音も大きくて良い商品ですが、実は大きな弱点があります。</p>
<!-- /wp:paragraph -->

<!-- wp:list -->
<ul class="wp-block-list"><!-- wp:list-item -->
<li><strong>ホームセンターの防犯砂利（ガラス発泡材など）</strong><!-- wp:list -->
<ul class="wp-block-list"><!-- wp:list-item -->
<li><strong>【弱点】とにかく軽い！</strong> 大雨が降ると水に浮いて流されてしまったり、強風で飛んでいってしまうことがあります。また、何度も踏んでいるうちに砕けて粉々になり、数年で補充が必要になることも…。</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>【価格】</strong> 1袋（10kg〜20kg）で買うと数百円〜千円程度ですが、家の周り全体に敷くとなると何十袋も必要になり、<strong>結果的にかなり割高</strong>になってしまいます。</li>
<!-- /wp:list-item --></ul>
<!-- /wp:list --></li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>石名坂の「5号砕石」</strong><!-- wp:list -->
<ul class="wp-block-list"><!-- wp:list-item -->
<li><strong>【強み】本物の石だから頑丈！</strong> 重さがあるので、大雨や台風でも流されたり飛んでいく心配がありません。踏んで割れることもなく、<strong>一度敷けば半永久的に効果が持続</strong>します。</li>
